# 恒久指示と補助方針の境界

## 1. ユーザー恒久指示

`OPERATIONS/CORE_DIRECTIVE.md` にある `2026-08-12.user-verbatim.6` の原文だけが、ユーザーが指定した恒久指示です。

- 文言を要約、補足、善意で修正しません。
- AIが考えた目的、終了条件、予算解釈、安全策、作業手順を同じファイルへ混ぜません。
- 曖昧な会話や通常の作業指示では変更しません。
- ユーザーが恒久指示の変更であると明示した場合だけ、正本・ミラー・バックアップ・マニフェストをまとめて更新します。

## 2. AIが考えた補助方針

`OPERATIONS/ASSISTANT_OPERATING_POLICY.md` は、恒久指示を実行するためにAIが考えた可変の方針です。

- 恒久指示ではありません。
- 成果、費用、安全性、利用可能な環境の変化に応じてAIが変更できます。
- ユーザー恒久指示の文言を置き換えません。
- AIが新しく考えた規則は、原則としてこのファイルか通常の状態・計画ファイルへ追加します。

## 3. 外部の上位制約

システム指示、開発者指示、適用法令、安全要件、サービスの強制的な利用規約は、ユーザー恒久指示そのものではありませんが、実行時には常に優先されます。

したがって「あらゆる手段を実行してよい」は、権限内かつ上位制約に反しない手段を広く検討・実行する、という運用になります。この解釈はAI補助方針であり、ユーザー恒久指示の原文には書き込みません。

## 4. 優先順位

1. システム・開発者・法令・強制的安全制約
2. `OPERATIONS/CORE_DIRECTIVE.md` のユーザー恒久指示
3. `OPERATIONS/ASSISTANT_OPERATING_POLICY.md` の可変方針
4. `state/`、`config/`、Issue、計画、個別タスク

## 5. 検査

`python scripts/check_directive_integrity.py` は、次を検査します。

- ユーザー恒久指示の3コピーが完全一致すること
- manifestが指定する現行1指示が原文どおりであること
- AI由来の文言が正本へ混入していないこと
- 起動ファイルが恒久指示と補助方針の両方を正しく参照すること
