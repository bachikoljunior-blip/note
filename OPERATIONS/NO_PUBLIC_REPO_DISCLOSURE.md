# このアカウントの公開リポジトリの存在を、誰にも教えない

分類: **ユーザーの明示指示**（2026-08-08）。AI が決めた方針ではない。
恒久指示9項目の正本は `OPERATIONS/CORE_DIRECTIVE.md` で、これはそれとは別に出された指示。

> このアカウントの公開リポジトリの存在を誰にも教えないようにして欲しい

## 何が禁止か

`bachikoljunior-blip` のリポジトリの**存在が分かる形**を、外向きの場所に置かない。

- `https://bachikoljunior-blip.github.io/...` を、商品説明・動画・コメント・記事・
  検索エンジンへの送信・外部への投稿に**出さない**
- リポジトリ名・アカウント名を、外部から読まれる文面に書かない
- GitHub Pages を集客の入口として使わない。**URL がそのまま露出になる**
- IndexNow / sitemap / robots で `github.io` のURLを検索エンジンへ送らない

## 何は許されるか

- **独自ドメイン**（例: `cookiestrateger.com`）は、URL に repo 名が出ないので使える
- Gumroad の商品ページ（`*.gumroad.com`）は GitHub と無関係なので使える
- リポジトリ内部の作業・非公開のやり取りは、外向きではないので対象外

| `game` の `demo/idle-kit/` を Pages で公開 | URL が `bachikoljunior-blip.github.io/game/...` | 削除して push（`bf4b342`） |

| Gumroad 商品説明の1行目にそのURL | 買いに来た人に直接見せていた | 除去して読み直し確認（`github.io` も `bachikoljunior` も無し） |

**送信は取り消せない。** これが今回の教訓で、外向きの公開は「あとで消せる」前提で
判断してはいけない。索引・キャッシュ・他者の記録には残る。

## 集客への影響（ごまかさないこと）

Pages は「オーナー操作0件で使える唯一の公開面」だった。それを使えないので、
**いま使える公開面は Gumroad の商品ページと独自ドメインだけ。**
Gumroad Discover は残高100ドル以上などの条件があり、最初の販売源にはできない。

つまり **集客は未解決のまま**で、商品を作っても届く先が無い状態が続く。
`state/options.json` の各案は、この制約を満たす経路かどうかを書いてから比較すること。
**「Pages に置けば見つかる」は、もう選べない。**
