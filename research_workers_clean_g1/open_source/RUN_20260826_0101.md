## Refinement A — Memento five-iteration control slope remains causally unresolved; paper text does not define the no-CBR iteration operator

### Observed

Paper Table 4 reports DeepResearcher performance over five iterations:

- Memento w/o CBR: 78.65 -> 80.93 -> 82.62 -> 83.53 -> 84.47 (+5.82 pp)
- Non-Parametric CBR: 79.84 -> 81.87 -> 83.09 -> 84.03 -> 84.85 (+5.01 pp)
- Parametric CBR: 80.46 -> 82.84 -> 84.10 -> 84.85 -> 85.44 (+4.98 pp)

The paper says the Case Bank has only about 3k training data and saturates quickly; later iterations contain progressively fewer previously unseen cases. It does **not** state, in the public paper text located in this run, what operation changes the `w/o CBR` arm between Iter 1..5: whether each round is a fresh stochastic rerun, failure-only retry, cumulative-best/ever-solved accounting, changed query order, resampling, or another protocol.

The same paper's OOD protocol is clearer: NQ/TQ/HotpotQA/2Wiki trajectories are collected into a case bank, then four relevant cases are retrieved for Musique/Bamboogle/PopQA. That clarity is absent for the Table-4 no-CBR iteration mechanics.

Primary paper source:

## Refinement B — Argus Manager transitions are mediator-bound, but Engineer containment is an integrity sandbox rather than proven transition-capability revocation

### Manager path: stronger than the earlier caller-boolean concern

At commit `455da6c...`, `_StageDecisionMixin` explicitly calls itself the Manager's sole stage-transition authority. The Manager model invocation is constructed with `sandbox_mode="read-only"` and `dangerous_yolo=False`. The model emits a structured stage decision; host-side code parses/finalizes it, derives `_allow_early_completion = (not open_ended and resolve_workflow_mode(root) == "direct")`, and only then calls stage-machine primitives from `_apply_stage_decision_to_disk`.

This means the normal **Manager decision-model path** does not trust a model-supplied `allow_early_completion` boolean. The host mediator derives that flag from authoritative workflow state and performs the actual mutation after parsing/checks.

Sources:
- https://github.com/microsoft/ArgusAgent/blob/455da6cb2fe10e9fbaeab5126f2f3b363237cf57/argus_skill/manager/_stage_ops.py
- https://github.com/microsoft/ArgusAgent/blob/455da6cb2fe10e9fbaeab5126f2f3b363237cf57/argus_skill/manager/stage_decider.py

### Engineer path: containment gate is default-OFF unless deployment enables it

`tests/test_engineer_sandbox.py` documents a gated, default-OFF engineer containment sandbox. When `ARGUS_SKILL_SAFE_MODE` is not enabled, the test expects requested read-only isolation to be removed and `dangerous_yolo=True` for supported backends. With the engineer gate enabled, Codex builder roles are converted to workspace-write and VCS credentials are scrubbed; writable roots explicitly exclude the Argus gate brain, package source, `.codex`, and the active venv.

Source:
- https://github.com/microsoft/ArgusAgent/blob/455da6cb2fe10e9fbaeab5126f2f3b363237cf57/tests/test_engineer_sandbox.py

### Important limit of what was proved

The containment tests prove **non-writability/integrity protection** for gate/package/venv paths when enabled. This run did not find a source-level contract proving that a builder/Engineer process is unable to *import and call* installed stage-machine functions that mutate project-local state. Read-only package code can still be callable in principle; whether the runtime blocks those imports/calls requires a direct sandbox/runtime test. Therefore the old run-13 direct-import failure is not fully answered by the current filesystem-write sandbox alone.

The transferable design is now more precise:

`model decision -> narrow mediator -> host-derived transition capability from authoritative state -> deterministic evidence validation -> mutation`

and, separately for builder roles:

`workspace write capability != authority to call control-plane mutation primitives`.

A robust design should make privileged transition functions unreachable or require an opaque capability/token checked inside the primitive, rather than relying only on package-file immutability or caller discipline.
