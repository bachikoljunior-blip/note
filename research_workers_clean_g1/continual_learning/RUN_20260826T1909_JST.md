## Routing-versus-shared-adaptation frontier: material update

The prior SinglePrompt result should not be generalized into “routing is unnecessary.” Public continual-learning evidence now separates into regimes.

### 1. SCALE — LLM continual pretraining: routing helps, but only modestly over a good static expansion
Primary source: Findings of ACL 2026, `SCALE: Upscaled Continual Learning of Large Language Models`.

SCALE freezes pretrained parameters and expands linear modules. SCALE-Route routes tokens between preserve/adapt heads by cosine similarity (reported threshold tau=0.5). In LLaMA3.2-1B Korean continual pretraining on 60B FineWeb2 Korean tokens, English/Korean averages are:
- base: 47.14 / 51.15
- FFT: 42.79 / 57.21
- LoRA: 42.59 / 57.25
- LLaMA Pro: 44.55 / 55.81
- Freeze: 42.44 / 54.67
- SCALE-Preserve: 46.09 / 53.14
- SCALE-Adapt: 46.15 / 55.09
- SCALE-Route: **46.49 / 55.50**

The direct static-vs-routing delta is therefore only +0.34 English average and +0.41 Korean average over SCALE-Adapt, while routing gains +2.36 Korean points over Preserve. Interpretation: static structural expansion captures most of the benefit in this controlled language-shift setting; routing is best but its marginal value over a good static adaptation path is small. Scope: controlled continual pretraining, not arbitrary task-free streams; the paper itself notes routing compute/memory/threshold sensitivity.

### 2. PASs-MoE — heterogeneous multimodal CIT: routing quality materially matters
Primary source: ACL 2026 `Pathway-Aware Self-Routing Mixture-of-Experts for Continual Instruction Tuning`; public implementation `yueluoshuangtian/PASs-MoE` inspected.

Structural ablation on MLLM-CTBench:
- MoE-LoRA top-k: AP 32.38, BWT -15.34
- MoE-LoRA softmax: AP 43.36, BWT -6.64
- top-k + PASs-RW: AP 46.31, BWT -4.24
- full PASs-RW + PASs-RS: **AP 48.46, BWT -2.15**

The public implementation confirms token/input-activation self-routing rather than a task-ID argument in the LoRA forward path. Router modes include QR/A/MLP/A-cos. In A-cos, current token representation and each expert's LoRA-A rank directions are normalized, positive cosine alignment is averaged into an expert score, scores are softmaxed, and all expert outputs are weighted and summed. This is a strong counterexample to a blanket “router complexity tax” claim: under heterogeneous multimodal continual instruction tuning, routing quality and pathway alignment are associated with large AP/BWT changes.

Scope guard: the training benchmark still has an explicit sequential task order/boundaries and uses a fixed seed in the reported setup. It is not a fully boundary-free stream. Also, the current public router code computes a balance statistic `f` from `(G > 0)` after softmax, which is trivially true for active experts; the code itself notes this legacy behavior. Whether that statistic enters the actual training loss must be traced before treating it as a reproducibility defect affecting reported results.

### 3. Controlled Subspace Fusion — shared low-rank adaptation remains a serious LLM alternative
Primary source: Information Fusion 2026 `Controlled Subspace Fusion`.

The method uses a shared low-rank projection subspace plus incremental subspace fusion, is rehearsal-free and task-agnostic at inference, and is evaluated on LLaMA2/T5 from 220M to 13B. The paper reports 40.5% fewer trainable parameters than O-LoRA in one LLaMA comparison and 93.6% lower parameter increment on its Large Number of Tasks setting while remaining competitive. Exact accuracy tables were not extracted in this invocation, so no stronger quantitative claim is made here.

Scope guard: sequential dataset/task boundaries are available during training; “task-agnostic” primarily describes inference. This is not evidence for a fully unlabeled boundary-free stream.

### 4. Selective-gradient suppression has an LLM mechanistic analogue, but not yet continual evidence
AAAI 2026 `DRIFT: Difference-Aware Reinforcement Through Iterative Fine-Tuning for Language Models` masks common subsequences between generation and ground truth so updates concentrate on error regions; its output-aware loss adds position-invariant vocabulary supervision. This is mechanistically close to SinglePrompt's finding that suppressing gradients on currently irrelevant outputs dominates prompt-routing ablations.

Representative non-continual results: Qwen leaderboard average 61.47 after SFT1 to 63.07 after DRIFT iteration 1; LLaMA 60.48 to 62.46. Removing difference-aware masking lowers the reported Qwen summarization ROUGE1 average from 47.29 to 46.49; removing output-aware loss gives 46.99.

Scope guard: this is iterative supervised fine-tuning, not a continual-learning benchmark. It is only evidence that selective local updating can be useful in LLM optimization, not that it prevents continual forgetting.

## DRIFT graph benchmark: public continuous-shift generator verified

The separate arXiv 2026 benchmark `DRIFT: A Benchmark for Task-Free Continual Graph Learning with Continuous Distribution Shifts` now has a public implementation at `UConn-DSIS/DRIFT`. The inspected `gaussian_utils.py` constructs task centers from natural batch windows, assigns softmax-Gaussian mixture weights by batch, converts them to fixed-size integer batch counts using largest-remainder rounding, samples each task stream and shuffles the combined batch. It also supports entropy-based sigma calibration. `pipeline.py` maps `tfo_gaussian` to this Gaussian stream path.

Reported TFO-Gaussian mean performance (GAT / GCN): Offline Joint 0.746/0.777; Fixed Backbone 0.754/0.778; Bare 0.503/0.539; LwF 0.608/0.582; EWC 0.555/0.526; TWP 0.495/0.603; ER-GNN 0.521/0.577; inverse-degree rehearsal 0.588/0.673. The large gap between fixed/joint upper controls and several adaptation/rehearsal methods is useful negative evidence against assuming that boundary-triggered adaptation is automatically helpful under smooth mixing.

Scope guard: current publication is arXiv/CoRR in the checked sources; do not treat it as a peer-reviewed final result yet. Fixed-backbone superiority in this setting is a benchmark-specific observation, not proof that adaptation is generally harmful.

## Revised synthesis

The high-value question is no longer “shared adapter or router?” but **when does distribution/task heterogeneity justify routing overhead?** Current evidence suggests a conditional hierarchy:
- When interference is mostly localized at the output/classifier and a shared representation remains adequate, simple shared adaptation plus selective negative-gradient suppression can dominate routing complexity (SinglePrompt vision evidence).
- Under a controlled language/domain shift, static expansion captures most of routing's gain, though routing remains best (SCALE).
- Under heterogeneous multimodal continual instruction tuning with expert specialization, routing quality can be decisive (PASs-MoE).
- Shared low-rank subspaces remain a parameter-efficient alternative in task-sequential LLM settings (CSF).

Candidate causal axes for a matched experiment: modality/domain heterogeneity; overlap of output label/vocabulary support; whether interference can be locally masked at the output; shared-versus-disjoint latent task structure; trainable-parameter and replay budget; smooth versus abrupt transition; and router inference/training overhead.
