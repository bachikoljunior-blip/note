## 2. New strong supervised task-free candidate: SinglePrompt shows prompt routing can be a complexity tax
Primary source: Park, Lee & Lee, `Is Prompt Selection Necessary for Task-Free Online Continual Learning?`, CVPR Findings 2026 / arXiv:2604.04420. Official code: `efficient-learning-lab/SinglePrompt`.

The useful intervention is unusually simple: one shared prefix prompt in the first K ViT layers, cosine-similarity class prototypes, and minibatch label masking. The paper explicitly studies task-free Si-Blurry streams with no task ID/boundary. However, this is **supervised task-free** continual learning: the current labels are available, and the training mask uses the labels in the current + replay minibatch. Official code confirms that it obtains `torch.unique(y)`, un-masks only those classes, and adds `-inf` to logits for absent classes during training. Inference is unmasked. Therefore this is not evidence for label-free drift adaptation.

### Prompt-selector ablation
On CIFAR100 (5 seeds), a 10-prompt learned similarity selector gives `A_auc 79.89±2.14 / A_last 82.12±1.66` with 560K learnable parameters; selecting among 10 prompts at random gives `79.78±2.03 / 81.85±1.78` with 553K. A single prompt with no selector gives `81.05±2.18 / 82.38±1.95` with 138K. Within this stripped comparison, learned prompt routing is almost indistinguishable from random selection, while removing the selector improves the reported mean and cuts learnable parameters by roughly 75%.

### Main task-free results
With no replay buffer, SinglePrompt versus the strongest reported MISA baseline:
- CIFAR100: `85.58±1.46 / 87.53±0.45` A_auc/A_last versus `80.55±2.17 / 80.98±1.08`.
- Tiny-ImageNet: `85.60±0.59 / 82.87±0.54` versus `80.44±0.80 / 74.84±0.64`.
- ImageNet-R: `59.00±1.16 / 58.88±0.53` versus `50.89±1.03 / 43.92±0.37`.
The A_last differences are +6.55, +8.03 and +14.96 points respectively. With buffers of 500 or 2000, SinglePrompt remains ahead of the reported MISA values on all three datasets.

Important comparison caveat: Table 2 baseline numbers are taken from MISA rather than re-run by the SinglePrompt authors in the same repository. MISA also uses an initial-session adaptation stage with pretraining data to warm up prompts. Treat the result as a strong reported comparison, not a newly matched same-code rerun.

### Component causality is more informative than the headline method
CIFAR100/no-buffer ablation:
- Full prefix+cosine+batch-mask, K=5: `A_auc 85.58±1.46 / A_last 87.53±0.45 / F_last 5.89±0.99`.
- Replace cosine prototypes with a linear classifier: `81.63±1.98 / 82.37±1.75 / 10.82±1.57`.
- Remove minibatch label masking: `65.57±5.17 / 51.81±3.39 / 48.19±3.89`.
The dominant measured mechanism is therefore not the prefix prompt itself but **local classifier-interference control**: preventing each supervised update from pushing on classes absent from the current minibatch. The cosine classifier also contributes materially.

Depth K has a broad optimum: K=3/4/5/6 produce A_auc about 85.1/85.1/85.6/85.7; deeper K=9/12 falls to about 84.9/85.0 and higher forgetting. Standard prompt tuning reaches `81.68/84.37/5.68`, LoRA `82.21/81.25/11.45`, AdaptMLP `83.74/84.34/9.07`. Prefix prompting does not dominate every metric: standard prompt tuning has slightly lower F_last, but substantially lower A_auc/A_last.

### Efficiency
On CIFAR100/no-buffer, reported learnable parameters / forward FLOPs / total time are:
- MVP: 562K / 34.21G / 2731.43 s
- MISA: 576K / 35.67G / 3405.24 s
- Online-LoRA: 524K / 17.64G / 1764.47 s
- SinglePrompt: 230K / 17.61G / 1589.74 s
FLOPs are forward-pass FLOPs, not full training FLOPs.

### Transferable hypothesis and exact scope
The high-value hypothesis is not “single prompts are universally best”. It is narrower: **when routing decisions themselves are noisy or redundant, a shared low-dimensional adaptation path plus an explicit local interference gate can outperform a larger dynamically routed prompt pool**. The current evidence is supervised vision with ImageNet-pretrained ViT-B/16 and class labels available at training time. Do not generalize this to unlabeled streams, LLMs, or all modular routing without new matched evidence.

## 3. New negative-evidence benchmark candidate: smooth latent-task mixing breaks sharp-boundary assumptions
Provisional source: `DRIFT: A Benchmark for Task-Free Continual Graph Learning under Distribution Shifts`, arXiv:2605.12998 (2026). It constructs task-free graph streams where latent task distributions mix continuously, including Gaussian overlap, rather than exposing sharp task boundaries.

The reported Gaussian-mixing results are a useful constraint: on Arxiv the best listed task-free method is around 34.9 AAUC while the offline joint upper bound is 71.6; on CoraFull about 34.1 versus 86.3; on Reddit about 39.9 versus 98.0. Several mechanisms that depend on an inferred shift trigger or task-partitioned memory degrade badly under smooth mixing. The manuscript reports, for example, MAS* on Reddit at 21.6 AAUC under Gaussian mixing versus Bare at 35.3, and CoraFull 30%-global ER at 49.0 versus task-partition-heavy SSM/SEM around 20–22.

This should be used as **benchmark negative evidence against assuming crisp boundaries**, not as proof that any one continual-learning mechanism is intrinsically poor. Scope is preprint, synthetic task-free streams derived from static graph datasets, node classification, and latent task definitions used to construct but not reveal the stream. Before elevating it beyond provisional status, re-check the final public artifact/code and seek peer-reviewed or independently reproduced results.

- https://arxiv.org/abs/2605.12998

## 4. Updated synthesis
Across the current clean evidence, a recurring decomposition is becoming sharper:
1. **What should be updated?** OASIS/sample selection, sparse/local adaptation, prototype/classifier masking.
2. **When should old experience be replayed?** FOREVER/model-time rather than fixed-step replay.
3. **How should an update be constrained?** OCAR/curvature, gradient alignment, local logit masking.
4. **What global optimization trajectory should be used?** Infinite-LR avoids destructive repeated re-warm.
5. **Should the system route among modules at all?** SinglePrompt provides direct evidence that a learned selector can add complexity without value in at least one supervised vision regime.
6. **Can the environment be segmented into clean tasks?** DRIFT/LargeMonitor/CLDD lines show that boundary quality and transition smoothness must be evaluated explicitly rather than assumed.

The new strongest actionable addition from this run is item 5 plus the ablation-defined mechanism in item 3: a useful continual learner should compare dynamic routing against a deliberately simple shared adapter with explicit interference control, not automatically treat more routing capacity as beneficial.
