### CLG1-CL-010 — HSIC-based label-independent model expansion is a genuine task-free boundary alternative, but capacity can grow dramatically and the expansion signal is not a one-to-one task detector
Primary source: Ye & Bors, Neurocomputing 2025, `Evolving Ensemble Model based on Hilbert Schmidt Independence Criterion for task-free continual learning`.

Mechanism:
- EEM maintains a finite streaming memory buffer and a growing ensemble of VAE/classifier experts.
- When the memory buffer is full, it compares latent distributions from the current memory against each trained expert using HSIC. If the minimum HSIC to existing expert knowledge exceeds threshold `lambda`, a new expert is created; the current memory trains that expert and is then cleared.
- The expansion decision is statistical and does not require task labels or task IDs. This directly addresses the clean frontier opened by the HESTIA implementation audit: unlike HESTIA's released main training path, the expansion trigger here is not an unseen-ground-truth-class check.
- Three buffer management variants are evaluated: sliding-window (EEM-SW), random dropout (EEM-Rand), and selective dropout (EEM-SD).

Exact benchmark evidence:
- Split MNIST / Split CIFAR10 / Split CIFAR100 classification accuracy, five independent runs:
  - CN-DPM: 93.23±0.09 / 45.21±0.18 / 20.10±0.12.
  - EEM-SW: 96.79±0.11 / 58.81±0.12 / 22.33±0.15.
  - EEM-Rand: 96.73±0.12 / 56.09±0.15 / 21.78±0.16.
  - EEM-SD: **97.02±0.17 / 59.03±0.23 / 23.26±0.14**.
  - For context, reservoir replay is 92.16±0.75 / 42.48±3.04 / 19.57±1.79; CoPE is 93.94±0.20 / 48.92±1.32 / 21.62±0.69.
- Complex-stream table, 20 runs:
  - Split MiniImageNet: EEM-SW 28.90±1.1, EEM-Rand 27.23±1.2; ER+GMED 27.27±1.8, MIR 25.21±2.2.
  - Permuted MNIST: EEM-SW 80.32±0.6, EEM-Rand 80.28±0.5; MIR+GMED 79.25±0.8.
- Fuzzy-boundary streams, five runs:
  - Split MNIST: EEM-SW 96.78±1.5, EEM-Rand 96.63±1.3 vs MIR+GMED 86.17±1.7.
  - Split CIFAR10: EEM-SW 57.32±1.3, EEM-Rand **58.27±1.5** vs MIR+GMED 41.22±1.1.
  - Split MiniImageNet: EEM-SW **28.63±0.8**, EEM-Rand 28.48±0.9 vs ER+GMED 28.20±0.6 and MIR+GMED 26.86±0.7.

Expansion/capacity evidence and scope:
- The final number of experts is 21 for Split MNIST, 25 for Split CIFAR10, and 7 for Split CIFAR100, despite those benchmarks having 5, 5, and 20 class-incremental tasks respectively. Therefore the expert count is explicitly **not** a reliable one-to-one estimate of latent task count.
- Reported total parameters are about 2.1e7 (Split MNIST), 5.3e8 (Split CIFAR10), and 1.5e8 (Split CIFAR100 / Split MiniImageNet). The strong label-independent expansion result therefore comes with potentially large architecture-growth cost.
- Expansion-threshold ablation on Split MNIST shows the expected sensitivity: with `lambda=0.380` the model remains at about two components and performance is poor; `lambda≈0.385` tracks transitions with far fewer excess components; `lambda=0.386` and `0.390` cause substantial over-expansion (roughly 18 and 30 components by the end in the plotted stream). The paper chooses the threshold as a compactness/performance trade-off rather than demonstrating a calibrated universal change-point score.
- Maximum streaming buffers are 2000 / 1000 / 5000 samples for Split MNIST / CIFAR10 / CIFAR100, and the learner sees only batches of 10 at each step.

Interpretation:
- This is the strongest clean evidence so far that a label-independent statistical shift signal can drive task-free structural expansion with useful accuracy, including fuzzy boundaries.
- It is **not** evidence for perfect task-boundary identification: the expansion count can greatly exceed or undershoot the benchmark task count, and threshold tuning strongly controls architecture growth.
- It is also not a matched control for same-label covariate shift in an LLM/agent setting; the experiments remain image-classification streams. Still, it supplies the mechanism class that the HESTIA released implementation currently lacks: boundary creation without target-label novelty.

Status: medium-strong label-independent boundary/expansion candidate; priority follow-up is a modern fixed-capacity or sparsely expanding comparator and a same-label domain-shift benchmark.

### CLG1-CL-011 — Prototype summaries plus per-parameter online hypergradient reweighting can convert offline prompt methods into task-free, single-pass continual learners; the two components are synergistic rather than individually sufficient
Primary source: Michel et al., TMLR 2026, `From Offline to Online Memory-Free and Task-Free Continual Learning via Fine-Grained Hypergradients`.

Mechanism:
- Start from memory-free offline continual methods such as CODA, L2P, DualPrompt, or ConvPrompt.
- Add lightweight class prototypes to recover online/task-free information. The paper observes that prototypes improve performance but increase gradient imbalance toward earlier tasks.
- Fine-Grained Hypergradients (FGH) then reweight parameter updates online to counter that imbalance. No explicit task boundary is required and samples are observed once.

Final TMLR Si-Blurry evidence (Average Performance %, selected rows; LR columns are the paper's tested settings):
- CODA on CIFAR100: baseline 15.14±3.78 / 71.12±4.47; `+ prototypes + FGH` 44.21±8.04 / 79.47±2.23. On CUB: 0.83±0.35 / 53.17±1.96 → 4.50±0.63 / 68.64±3.19. On ImageNet-R: 1.92±0.62 / 47.65±1.40 → 9.95±1.79 / 57.16±1.17.
- L2P on CIFAR100: 10.80±4.39 / 58.20±6.59 → 33.05±8.01 / 79.22±3.02. CUB: 0.46±0.24 / 30.57±3.85 → 2.00±0.98 / 68.68±2.29. ImageNet-R: 1.05±0.29 / 27.17±4.61 → 5.80±1.47 / 59.89±2.05.
- DualPrompt on CIFAR100: 15.68±3.53 / 66.90±5.04 → 42.12±6.34 / 75.23±3.21. CUB: 0.97±0.42 / 52.32±2.40 → 5.43±0.98 / 74.89±1.51. ImageNet-R: 1.80±0.39 / 46.05±1.74 → 10.11±1.38 / 57.68±1.70.
- ConvPrompt on CIFAR100: 24.55±3.80 / 75.01±5.16 → 44.23±3.29 / 86.34±3.59. CUB: 0.64±0.23 / 56.27±0.84 → 4.43±1.13 / 73.88±0.87. ImageNet-R: 1.18±0.02 / 46.75±1.80 → 3.78±0.22 / 62.62±0.11.

Ablation interpretation:
- The paper's component analysis shows prototypes alone often deliver the large first jump, while FGH alone can be weak or harmful; FGH's value appears when paired with prototype-induced information and the associated gradient imbalance. Example CODA/CIFAR100 at one reported setting: baseline 15.14±3.78, +prototype 31.27±6.95, +FGH 22.27±5.88, +prototype+FGH 44.21±8.04.
- Hence the transferable mechanism is not “hypergradients always improve online CL”; it is **compressed summary memory creates useful but biased update pressure, and online hypergradient reweighting can correct that pressure**.

Scope/caveats:
- This is class-incremental vision, so class labels/prototypes remain available. It is task-free with respect to boundaries/task IDs, not label-free and not a same-label domain-shift detector.
- It avoids replaying raw samples but still stores class prototypes; “memory-free” in the paper's terminology means no episodic sample replay, not literally zero durable statistics.
- The exact best setting is learning-rate/hyperparameter dependent; do not collapse the two columns into a universal gain.

Status: medium-strong control for boundary-free online adaptation and a useful counterpoint to expansion-based methods such as HESTIA/EEM.

### CLG1-CL-012 — Replay to a world model with a fixed-budget short-term/long-term split can sharply reduce forgetting even when dynamics and reward functions change; this relaxes the fixed-dynamics limitation of CLG1-CL-001
Primary source: Alyahya et al., TMLR 2026, `ARROW: Augmented Replay for RObust World models`.

Mechanism:
- ARROW extends DreamerV3 with two equal-size buffers under a fixed total replay capacity of `2^19 ≈ 0.52M` observations: a short-term FIFO buffer (`2^18`) for recency/plasticity and a long-term global-distribution-matching reservoir (`2^18`) for stability.
- Minibatches sample uniformly between the two buffers. All baseline methods use the same total replay-observation budget.
- The agent trains its world model on real replay; actor/critic updates are performed on imagined trajectories from that model. Thus old experience primarily preserves a predictive dynamics/reward representation rather than directly rehearsing a model-free policy.

Why this resolves a clean frontier:
- CLG1-CL-001 (online world-model planning) had its strongest evidence when tasks shared dynamics and only rewards changed. ARROW explicitly includes six unrelated Atari games, where environment dynamics, observations, and reward functions differ substantially, as well as six structurally related CoinRun variants.
- This is not the same algorithmic claim as CLG1-CL-001, but it is direct evidence that continual world-model learning can retain knowledge outside the fixed-dynamics/reward-only regime.

Exact matched-budget Atari evidence, median [IQR] over 5 seeds:
- Default task order:
  - ARROW forgetting **0.115 [0.093–0.219]**, FT -0.190 [-0.216–-0.105], ACC 0.553 [0.498–0.687], min-ACC 0.546 [0.485–0.616], WC-ACC **0.470 [0.420–0.522]**.
  - DreamerV3 forgetting **2.263 [2.062–2.732]**, FT 0.612 [0.285–0.813], ACC -0.029 [-0.046–0.131], min-ACC -0.249 [-0.265–-0.181], WC-ACC -0.141 [-0.152–-0.128].
  - TES-SAC forgetting 0.192 [0.151–0.213] but ACC -0.010 and WC-ACC -0.114; the paper correctly notes low forgetting is misleading because TES-SAC mostly fails to learn the Atari tasks at this memory budget.
- Reversed order: ARROW forgetting 0.264 [0.220–1.012] vs DreamerV3 0.893 [0.744–0.983], with ARROW WC-ACC 0.482 [0.427–0.493] vs DreamerV3 -0.049 [-0.090–-0.036].
- Two-cycle: ARROW Max-F **0.081 [-0.037–0.244]** vs DreamerV3 **1.121 [0.899–1.177]**; ARROW recovery 2.450 [1.657–4.592] vs DreamerV3 0.729 [0.673–0.798]. ARROW WC-ACC 0.309 [0.300–0.394] vs DreamerV3 -0.226 [-0.287–-0.174].

Exact matched-budget CoinRun evidence:
- Default order: ARROW forgetting 0.154 [0.103–0.243], FT 0.257 [0.232–0.324], WC-ACC 0.539 [0.520–0.621]; DreamerV3 forgetting 0.416 [0.371–0.541], FT 0.503 [0.455–0.535], WC-ACC 0.263 [-0.331–0.366].
- Reversed order: ARROW forgetting **-0.062 [-0.108–-0.060]** (backward transfer) and WC-ACC **0.898 [0.795–0.972]**; DreamerV3 0.340 [0.197–0.482] and 0.689 [0.625–0.806].
- Two-cycle: ARROW Max-F 0.023 [-0.061–0.043], recovery 1.164 [1.140–1.190], WC-ACC **0.783 [0.745–0.794]** vs DreamerV3 Max-F 0.184 [0.126–0.441], recovery 1.207 [1.092–1.551], WC-ACC 0.041 [-0.041–0.217].

Stability-plasticity / buffer-ratio ablation:
- At fixed total memory, increasing long-term-buffer share from AR25 (75% FIFO / 25% LTDM) toward AR75 (25% FIFO / 75% LTDM) tends to reduce Atari forgetting while reducing forward transfer; no split dominates every setting.
- Atari default order: AR25 forgetting 0.341 / FT -0.087 / WC-ACC 0.361; AR50 0.115 / -0.190 / 0.470; AR75 **0.019** / -0.470 / **0.518**.
- Reversed order and two-cycle move the best WC-ACC toward AR50 while AR75 retains the lowest forgetting/Max-F. Seed IQRs overlap substantially, so the paper adopts 50/50 as a robust midpoint rather than claiming it is an optimum.
- CoinRun behaves differently: with shared structure, forgetting is already small and AR25 can lead the default-order metrics. Therefore the short-/long-term memory allocation should be treated as an environment-dependent control variable, not a fixed constant.

Critical caveats:
- Only 5 seeds and two 6-task suites; task order robustness is checked with default/reverse/two-cycle rather than a broad random-order sweep.
- ARROW has a real plasticity/sample-efficiency cost on unrelated Atari tasks: in the default order ARROW does not reach the global 85%-of-peak threshold in any seed, while DreamerV3 does in 4/5. The retention improvement must therefore not be summarized without this cost.
- This is world-model RL with fixed replay memory, not evidence that parameter-only continual learning or language-model continual pretraining gets the same benefit.
- The long-term sampler is reservoir/global distribution matching; the authors themselves frame the contribution as the integrated recipe rather than a novel sampling primitive.

Status: strong world-model continual-learning candidate and the clearest clean evidence so far outside the fixed-dynamics limitation of CLG1-CL-001.

### Task-order branch delta — approximately 1% pilot data can be enough to choose a useful curriculum; 0.1% is too noisy in the tested image setting
Primary source: Li & Hiratani, ICML 2025, `Optimal Task Order for Continual Learning of Multiple Tasks`.

New exact scope from the appendix:
- Task similarity is estimated by zero-shot transfer between task-specific models and then used to derive two order rules: periphery-to-core (least representative task first, most typical last) and max-path (adjacent tasks as dissimilar as possible).
- On CIFAR-10, estimating task similarity with only **1% of training data** produced a task-order performance gain comparable to the full-data similarity estimate; at **0.1% (~10 samples per task)** the gain became statistically non-significant.
- Similar trends were reported on Fashion-MNIST and CIFAR-100, but CIFAR-100 was less robust in the negative-similarity regime.
- The paper reports roughly seven-fold best-vs-worst differences in its synthetic five-task chain example, but that ratio is a synthetic-error result and must not be transferred to real image accuracy.

Interpretation:
- The mechanism becomes much more actionable for autonomous curriculum generation because the information cost of estimating task relations need not be full-task training data.
- It still assumes a controllable task set and future-task access sufficient to estimate pairwise similarity; it does not solve uncontrolled real-time streams.

Status: provisional-to-medium curriculum candidate; exact real-image accuracy deltas remain figure-only and should be extracted visually before ranking against replay/control mechanisms on a common budget.

## Rejected / downgraded / corrected claims
- Do not describe EEM expert count as detected task count. Its expert counts (21/25/7) differ sharply from benchmark task counts (5/5/20).
- Do not describe EEM as low-capacity merely because its buffer is bounded; dynamic experts can push total parameters to hundreds of millions on the reported vision benchmarks.
- Do not claim EEM has a universal threshold. Expansion/performance changes strongly with `lambda`, and the ablation demonstrates over-expansion at larger thresholds.
- Do not equate FGH with zero memory. The method is memory-free in the no-raw-replay sense but retains class prototypes/statistics.
- Do not claim FGH alone explains the gains. Prototype-only improvements are often large, and the strongest results come from the prototype + FGH interaction.
- Do not summarize ARROW by forgetting alone. ARROW incurs a clear forward-transfer/sample-efficiency cost on unrelated Atari tasks, while DreamerV3 can learn new tasks faster and then forget them.
- Do not claim 50/50 short/long-term memory is optimal. ARROW's ratio ablation shows environment/order-dependent stability-plasticity trade-offs and overlapping IQRs.
- Do not infer broad random-order robustness for ARROW; only default, reverse, and two-cycle curricula were tested.
- Do not transfer Li–Hiratani's synthetic seven-fold best/worst effect to real image accuracy. The real-data result is robust ordering advantage, with 1% pilot-data sufficiency, not a seven-fold accuracy claim.
