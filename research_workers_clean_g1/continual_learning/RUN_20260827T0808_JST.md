## SAFE-Merge is now quantitatively pinned as a protected-write/model-composition candidate

Primary source: Qiu et al., `SAFE-Merge: Data-Free Continual Model Merging with General Knowledge Preservation`, arXiv:2608.01184, submitted 2026-08-02. Primary manuscript/PDF inspected from a public arXiv mirror; all numerical claims below come from the paper tables/appendix, not secondary summaries. Source: https://arxiv.org/abs/2608.01184

Mechanism: risk-aware sparse masking first selects task-vector coordinates that appear useful for the incoming specialized checkpoint while posing lower risk to pretrained/general knowledge. Masked low-rank recovery then recovers task information lost through masking without modifying the masked-out support. The recovered update is fused into the backbone. Recovery factors and masks are discarded after fusion, so there is no task-bank/router or extra inference-time parameter/latency in the reported deployed model.

### Main CLIP ViT-B/32 long-horizon results versus NUFILT

Metrics are task ACC / held-out generalization Gen / harmonic H-score / BWT, averaged over 10 random task permutations (seeds 42–51):

- 8 tasks — NUFILT `83.6±0.2 / 52.3±0.3 / 64.3±0.2 / -2.7±0.7`; SAFE-Merge `83.0±0.3 / 56.7±0.2 / 67.4±0.2 / -3.5±0.6`.
- 14 tasks — NUFILT `78.0±0.2 / 49.4±0.2 / 60.5±0.2 / -5.7±0.9`; SAFE-Merge `79.2±0.4 / 56.4±0.2 / 65.9±0.2 / -4.8±0.6`.
- 20 tasks — NUFILT `71.0±0.9 / 44.5±0.4 / 54.8±0.3 / -8.9±2.3`; SAFE-Merge `73.5±0.5 / 54.9±0.4 / 62.9±0.4 / -8.2±1.3`.

The 8-task result is a useful scope guard: SAFE-Merge sacrifices 0.6 task ACC and 0.8 BWT relative to NUFILT while gaining 4.4 Gen and 3.1 H-score. At 14/20 tasks it also improves ACC and BWT versus NUFILT, and the general-knowledge gap widens. Therefore SAFE-Merge should be treated as a stability/general-knowledge trade-off method, not as universally better on every forgetting metric.

### Component ablation: masking is primary; unconstrained recovery is unsafe at long horizon

ViT-B/32 ACC / Gen / BWT:

- 8 tasks: naive accumulation `62.0 / 23.5 / -18.9`; mask only `80.7 / 52.3 / -4.0`; recovery only `79.1 / 47.2 / -10.1`; both `83.0 / 56.7 / -3.5`.
- 14 tasks: naive `46.4 / 19.1 / -25.8`; mask only `75.2 / 52.7 / -5.6`; recovery only `54.2 / 32.4 / -22.2`; both `79.2 / 56.4 / -4.8`.
- 20 tasks: naive `34.2 / 10.1 / -24.9`; mask only `63.3 / 44.0 / -11.1`; recovery only `38.0 / 19.5 / -34.0`; both `73.5 / 54.9 / -8.2`.

This is stronger mechanistic evidence than the abstract: risk-aware masking supplies most of the safe-support benefit. Low-rank recovery by itself becomes highly unstable as the sequence lengthens; at 20 tasks its BWT is `-34.0`, worse than naive accumulation. Recovery becomes useful when constrained to the support defined by the mask: adding recovery on top of the 20-task mask-only variant gives +10.2 ACC, +10.9 Gen and improves BWT from -11.1 to -8.2. Any reconstruction should therefore compare `mask-only` and `mask+recovery`; a recovery-only implementation is not a faithful safe-write surrogate.

## Updated interpretation / experimental consequence

The strongest new lesson is that continual-learning evaluation needs two kinds of retained knowledge: retention of previously acquired task-specific performance and preservation of broad pretrained/general capabilities. SAFE-Merge can improve the latter even when conventional BWT is unchanged or worse. For the existing matched data-mixing/model-composition contract, keep at least three independent endpoints: current/acquired-domain performance, backward retention, and held-out general-knowledge preservation. For protected-write model composition, compare a risk-aware mask-only baseline against mask+recovery; do not attribute the full method's effect to low-rank recovery alone.

Scope guard: SAFE-Merge operates on a sequence of already specialized checkpoints and is data-free at merge time. It is not evidence for raw-sample online SGD, boundary-free task discovery, continual pretraining without specialized checkpoint boundaries, or task-free routing.
