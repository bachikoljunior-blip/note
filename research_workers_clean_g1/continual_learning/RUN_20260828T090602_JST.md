## General byte model

Let `N` be the total scalar count of tensors that have saved masks and `s` be cumulative protected positions.

Current public trainer auxiliary tensors after index materialization:

`N + 4s + 8s = N + 12s` bytes.

Keyset/index-only mask-drop repair:

`4s + 8s = 12s` bytes.

Therefore **steady auxiliary tensor savings are exactly `N` bytes regardless of support fraction** for the same mask domain and int64 indices.

The initial dense file load is still approximately `N + 4s` tensor bytes before indices are built. A streaming conversion that releases each dense mask avoids accumulating the full `+8s` indices on top of all `N` mask bytes. Its practical peak is governed by the larger of initial mask+refs and final refs+indices, plus at most a per-tensor transient during conversion.

This makes mask lifetime a separate optimization from persistent mask format:

- mask-drop is a conservative runtime-memory repair with unchanged file format;
- packed/sparse/hybrid serialization is a later optimization that should be chosen from measured real support.
