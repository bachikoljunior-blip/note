## Critical invariant — do not replace the global support denominator with rank-local support

A naive implementation might localize state and also change

`scale = lambda / global_n_masked`

to

`scale = lambda / local_n_masked`.

That is not an equivalent transport optimization. It changes the algorithm and makes coordinate scale rank-dependent when protected support is imbalanced.

Concrete counterexample:

- `lambda = 100`, `W = 4`, global support = `40`;
- rank-local support counts = `[20, 5, 0, 15]`.

Public release pre-reduce coordinate scale is `2.5` on every nonempty rank and, under the previously established DeepSpeed averaging path, `0.625` post-average. Naive local denominators yield post-average scales `1.25`, `5.0`, and `1.6667` on the nonempty ranks.

Thus **rank localization and distributed-scaling correction must remain independent axes**. If correcting the known public owner-only `1/W` attenuation later, do it explicitly with world-size scaling; do not obtain an accidental, support-imbalance-dependent correction by changing the denominator.

## New executed result 2 — searchsorted rank slicing avoids the O(s) partition boolean

Durable artifact: `CPO_ZERO3_SEARCHSORTED_PREPARTITION_RESULT_20260828T100345_JST.json`.

Because CPO's `_mask_flat_idx` is sorted and refs are stored in the same flat-mask order, the one-time partition can be written as:

1. `global_n_masked = flat_idx.numel()`;
2. `P = ceil(ds_numel / W)`;
3. `start = rank*P`, `end = min(start+P, ds_numel)`;
4. `lo = searchsorted(flat_idx, start)`, `hi = searchsorted(flat_idx, end)`;
5. `rank_global_idx = flat_idx[lo:hi].clone()`;
6. `rank_ref = ref[lo:hi].clone()`;
7. optionally `rank_local_idx = rank_global_idx - start`.

A second randomized execution compared this against boolean partition filtering across:

- 5,000 parameter trials;
- 82,760 rank cases;
- world sizes 1–32;
- support up to 50%.

Result: **0 index/ref mismatches**.

The `.clone()` is required for memory release: a normal tensor slice shares the original storage, so retaining a slice without cloning can pin the entire global idx/ref allocation and defeat the steady-state memory objective.
