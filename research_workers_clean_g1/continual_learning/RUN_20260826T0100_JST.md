## 2. New transferable comparator: TFIDD provides explicit alarm-stability controls and direct FAR/delay metrics
Primary source: Eluchuri Bavaghna et al., *TFIDD: Adaptive dynamics for fast model-agnostic drift detection*, Scientific Reports, published 2026-07-16, DOI `10.1038/s41598-026-60128-2`.

Mechanism:
- monitor temporal feature-importance vectors rather than raw prediction error;
- adaptive Top-k feature selection;
- cosine-divergence drift score and exponential smoothing;
- threshold by a high quantile of a rolling reference-score buffer;
- require persistent violations before alarm;
- temporarily freeze detection after an alarm to suppress repeated triggers.

The paper's parameter discussion gives a useful explicit control baseline: `threshold_quantile q=0.9`, `alarm persistence m=4`, `freeze_after_alarm=5` batches, `score_window=50`, feature-importance history `W_max=25`, drift-score smoothing factor reported as about `0.15`, and a separate importance-smoothing coefficient `0.7`. It also reports a warm-up description that is not perfectly clean: an earlier methods passage says two mini-batches were used to initialize scaling/model weights before detection, while the parameter discussion refers to a detector warm-up of 8 batches. Treat these as potentially distinct initialization stages unless source/code clarifies them; do not collapse them into one exact value.

Detection evidence:
- SEA abrupt-drift aggregate: FAR `0.0278 ± 0.0048`, delay `4.10 ± 1.16` chunks, post-drift accuracy `0.8426 ± 0.0166`.
- Annotated Gas Sensor: FAR `0.0023 ± 0.0047`, delay `3.11 ± 1.93` chunks, post-drift accuracy `0.6929 ± 0.0557`.
- Forest CoverType full TFIDD: FAR `0.0215 ± 0.0017`, delay `2.92 ± 0.24` chunks, post-drift accuracy `0.7997 ± 0.0330`.
- Forest CoverType no-freeze ablation lowers delay to `2.14 ± 0.32` but raises FAR to `0.0242 ± 0.0010`, supporting a stability-response tradeoff. However the paper also reports streams where removing freeze does not worsen FAR, so freeze is not a universally positive component.

Scope/caveats:
- TFIDD is evaluated on tabular/sensor/data-stream benchmarks and uses evolving predictive-model feature importance; it is **not** direct evidence for zero-shot same-label vision drift detection.
- Its released GitHub repository `ELUCHURI-BAVAGHNA/TFIDD-SR` at observed head `9fbfa085a1ccce1cc6aadd18c698f316af082930` currently contains only `README.md` plus a `plots/` tree. No detector implementation source is present in the top-level release inspected. Thus numerical paper evidence is usable, but artifact reproducibility is weaker than the article's repository wording suggests.

Transfer hypothesis (untested): use TFIDD-style quantile calibration + persistent violations + post-alarm freeze as a matched alarm-control baseline on top of a frozen representation drift score such as `1-CKA`. This would test whether LargeMonitor's gains require its underspecified CUSUM stage or mainly require a stable pretrained representation plus a well-calibrated alarm controller. This is an experiment proposal, not evidence that the transfer works.

## 3. Evaluation contract strengthened by the 2026 concept-drift benchmark framework
Primary/public paper: *A Framework for Evaluating and Benchmarking Concept Drift Detection Methods*, arXiv:2606.07789 (2026), KDD 2026 benchmark work.

The framework makes a useful detector-evaluation contract explicit: precision, recall, Episode Recall, F1 detection score, Normalized Detection Time (NDT), Alarm Rate, and False Alarm Rate, with an acceptable detection window around each drift episode. NDT excludes missed episodes, so it must be interpreted jointly with Episode Recall. Crucially, it advocates leave-one-dataset-out hyperparameter optimization rather than tuning thresholds on the same evaluation stream.

For this clean frontier, that means LargeMonitor's qualitative/peak-window boundary claims should not be considered sufficient. Any reconstruction or alternative alarm controller should report at minimum Episode Recall + FAR + NDT under held-out calibration, and should separate raw monitoring quality from downstream continual-learning accuracy.
