### Current public defaults do not reproduce the paper protocol unless overridden

The paper reports 100 TPE trials, proxy scoring on the first 100 examples/task, and top-3 re-evaluation on the first 300 examples/task. The current public script defaults are:
- `--n-trials 50`;
- `--proxy-limit 300`;
- `--top-k 3`;
- `--top-k-limit 100`.

Thus the public defaults effectively reverse the paper's `100 proxy / 300 top-K` sample limits. All are configurable, so this is a reproducibility-contract mismatch rather than an algorithmic defect.

The public script also constructs `TPESampler`, `CmaEsSampler`, or `RandomSampler` without an explicit seed, and uses Python's unseeded `random.randint` for evaluation-start staggering. A reproducible rerun must explicitly seed the optimizer sampler and Python/NumPy/Torch/evaluation sampling paths and persist the study DB plus environment/model hashes.

### High-impact path-label collision in the current public search script

The script derives each CPT parameter label as:

`Path(model_path).parent.name or Path(model_path).name`

and then creates Optuna parameters named `w_<derived_name>`. The official README example supplies sibling directories such as `/path/to/japanese_ckpt` and `/path/to/math_ckpt`; both have the same parent directory `to`. Under that layout, both requested weights become the same Optuna parameter name (`w_to`). Optuna returns a single value for repeated suggestions of the same parameter name and compatible distribution, so the current public code can silently **tie multiple CPT weights together** instead of optimizing them independently.

This is a concrete defect in the currently published search script/example contract. It must not be projected backward onto the paper's internal experiments: the paper predates the public code release, and the reported experiments may have used a different internal path layout or implementation. A safe reconstruction should derive unique stable names from each resolved CPT directory basename or require explicit unique `--cpt-name` identifiers and assert uniqueness before creating the study.

### Negative-weight reproduction also needs an explicit override

The script defaults `--w-cpt-range 0.0 1.0`. The paper's negative-weight experiments require a range including negatives, e.g. `--w-cpt-range -1 1`. Therefore running the README defaults cannot reproduce the paper's subtraction/interference ablation.
