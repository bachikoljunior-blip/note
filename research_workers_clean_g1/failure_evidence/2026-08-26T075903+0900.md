## New claims

### FE-065 — A red-team reward can improve the attacker’s nominal fooling rate while making the generated hard negatives worse enough to damage the next defender
**Status:** primary arXiv v1, matched ablation in SPARED; image-forgery detector setting, not LLM jailbreak evaluation.

Primary source:
- Bao et al., *SPARED: Reasoning-Based AI-Generated Image Detection via Adversarially Edited Data*, arXiv:2608.12876v1 (2026-08-13): https://arxiv.org/abs/2608.12876

Evidence:
- SPARED trains an image-editing attacker against a **frozen defender snapshot**. The gated reward credits fooling only if an instruction-fidelity score passes threshold 0.7.
- Removing that gate at matched attacker budget makes the attacker pass instruction fidelity **9.6 points less often**, reduces median edit magnitude by **27%**, and nevertheless fools the frozen defender **slightly more**.
- Training the next defender on this ungated pool hurts rather than helps: DeepfakeJudge-Detect accuracy falls from Iter1 **72.1% to 66.7%**, whereas the gated adversarial round reaches **76.0%**. AnomReason-Deepfake accuracy falls from **85.72% to 81.12%**, whereas the gated round reaches **87.58%**.
- The paper reports real recall collapsing to **38.2%** while fake recall rises to **95.1%**, consistent with barely edited samples teaching a shortcut rather than a robust boundary.

Failure implication: attacker “win rate” against a frozen target is not sufficient quality control for red-team-generated training data. A reward that permits degenerate wins can make the attacker look stronger while poisoning the defender update. Scope is limited to SPARED’s image-editing attacker, fidelity gate, datasets, and one-round ablation; it does not establish that all ungated red-team RL behaves this way.

### FE-066 — Monotonic aggregate hardening can hide a large subgroup regression
**Status:** same primary SPARED study; external unseen-generator transfer breakdown.

Evidence:
- On Holmes-Set, mean accuracy rises from Iter2 **90.2%** to Iter3 **92.8%**.
- Over the same update, the Janus generator family drops from **86.5% to 73.1% (-13.4 pp)** while every other family improves.
- Adding in-domain data later recovers Janus to **84.3%**, suggesting the regression is not simply a permanent loss of model capacity.
- Authors attribute the failure to a hard 0/1 fooling reward with no per-family difficulty control, allowing a region no longer exercised by the harder pool to regress while the mean improves.

Failure implication: aggregate robustness improvement is not evidence of monotonic coverage across attack/generator families. Per-family slices can regress materially under adaptive hardening even when headline means rise. This is a detector/generator-family result, not a general theorem about adversarial training.

### FE-067 — More optimization or fresher data does not substitute for an attacker that adapts to the current defender in this matched control
**Status:** primary SPARED ablation; positive control delimiting FE-065/066 rather than a failure of adaptive training itself.

Evidence from a common Iter1 starting point on DeepfakeJudge-Detect:
- Iter1: **72.1%** accuracy.
- Continued GRPO on the frozen static round-one pool using **4.7×** budget: **74.3%**.
- Fresh-source pools regenerated with a **frozen base editor**, using **7.1×** budget: **73.7%**.
- One gated adaptive adversarial round (Iter2): **76.0%**.
- Full adaptive schedule through Iter3: **79.5%**.
- The paper reports the static branch peaking early and then declining, while fresh-source/frozen-attacker training oscillates below the adaptive schedule despite greater budget.

Implication: the negative evidence above should not be misread as rejecting attacker–defender co-evolution. In this exact experiment, adaptation to a frozen current defender adds value beyond more updates or merely refreshing source images; the critical failure is shortcut-prone attacker objectives and uneven coverage.

### FE-068 — Static heuristic red agents can substantially overstate DRL cyber-defender robustness relative to an adaptive learned red policy
**Status:** primary arXiv abstract-level evidence; exact relative-degradation metric is paper-specific and should not be interpreted as bounded accuracy loss.

Primary source:
- Masukawa et al., *Trident: How to Break Deep Reinforcement Learning Cyber Defenses (Agentic)*, arXiv:2608.04317 (2026-08-05): https://arxiv.org/abs/2608.04317

Evidence:
- Trident evaluates DRL blue defenders in CybORG CAGE 4 and CyberWheel against a trainable 7B LLM Planner in a Summarizer–Planner–Coder red-agent stack.
- The paper reports that the learned adaptive red agent reduces blue-agent defensive performance by an **average 522% relative to static red-agent baselines**, while discovering behaviors such as decoy avoidance and adaptive state prioritization that static heuristics do not exercise.
- The training corpus contains **over 13,000** red–blue interaction trajectories according to the primary abstract.

Failure implication: robustness measured only against fixed scripted/heuristic adversaries can be badly miscalibrated when the deployed threat can learn from interaction structure. Scope guard: the 522% figure is a relative change in the study’s defense-performance metric across these cyber ranges, not a percentage-point drop in a [0,100] accuracy; this run did not recover the primary full-paper per-defender table, so no finer numeric breakdown is promoted here.
