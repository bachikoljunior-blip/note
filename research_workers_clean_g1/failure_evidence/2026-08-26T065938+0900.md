## New claims

### FE-061 — Package-hallucination defense ranking changes sharply with threat model; standard-prompt results do not identify the best adversarial defense
**Status:** ASE 2026 primary full-paper tables; 8 models × 4 languages, three runs per configuration. Standard and adversarial prompt sets differ, so this is condition-dependent ranking evidence, not a paired causal estimate on identical prompts.

Primary source:
- Djire et al., *Evaluating Inference-Time Defenses Against Package Hallucination in LLM-Generated Code*, arXiv:2608.22652 / ASE 2026: https://arxiv.org/abs/2608.22652

Matched-table evidence:
- On standard prompts, the paper reports that RAG increases package-hallucination rate for **7/8 JavaScript models**, by **+12.7 percentage points on average** relative to Vanilla.
- Gemma-1b / JavaScript standard PHR: Vanilla **33.7**, Greedy **13.2**, Self-Refine **32.0**, Contrastive Decoding **23.9**, DoLa **17.1**, Nudge **14.4**, **RAG 60.9**, ALCD **22.2**. RAG is therefore much worse than several decoding-only controls in this exact cell.
- Qwen-1.5b / JavaScript standard PHR: Vanilla **40.4**, Greedy **18.0**, Self-Refine **22.6**, CD **28.7**, DoLa **16.8**, Nudge **12.3**, **RAG 47.5**, ALCD **28.6**.
- Under adversarial prompts seeded with fabricated package names, the ordering changes. Gemma-1b / JavaScript: Vanilla **77.0**, Greedy **76.8**, Self-Refine **78.5**, DoLa **88.5**, **RAG 49.2 (best)**, Nudge **84.8**, CD **77.6**, ALCD **88.6**. Qwen-1.5b / JavaScript: Vanilla **65.4**, Greedy **63.1**, Self-Refine **55.6**, DoLa **79.6**, **RAG 46.9 (best)**, Nudge **72.5**, CD **75.9**, ALCD **75.9**.
- Across all adversarial model-language cells, RAG is best in **16/32**; RAG or Self-Refine is best in **29/32**. For JavaScript specifically, RAG is lowest-PHR in **5/8** adversarial cells, unlike its standard-prompt degradation.

Failure implication: reporting only standard-prompt defense rankings can mislead deployment decisions under fabricated-dependency attacks. Threat model, language, model, and package-resolution/scoring rules must be part of the claim. The evidence does **not** show that adversarial prompting causally improves RAG, because standard and adversarial prompt sets are different; it shows that relative defense ordering is highly condition-dependent.

### FE-062 — A factuality-oriented decoding intervention can amplify adversarial fabricated-package anchors relative to Greedy decoding
**Status:** same ASE 2026 primary table; bounded to the tested small open-weight coding models, languages, fixed strategy hyperparameters, and fabricated-package adversarial prompts.

Evidence:
- Under adversarial prompts, **DoLa is worse than Greedy in 24/32 model-language configurations**.
- The largest reported gaps include DeepSeek-1.3b / Rust: Greedy **38.6** vs DoLa **94.1**, a **+55.5 pp** PHR increase; Gemma-4b / Rust and Mistral / Rust also show large DoLa regressions (about **+37.6 pp** and **+35.2 pp**, respectively).
- ALCD improves over DoLa in **23/32** adversarial cells but is the best strategy in **0/32** and beats Vanilla in only **6/32**, so “more sophisticated decoding” is not a monotonic robustness axis in this grid.

Failure implication: a decoding method motivated by factuality can strengthen an attacker-supplied dependency anchor rather than suppress it. This does not establish that DoLa is generally harmful or that these fixed hyperparameters are optimal; it establishes a concrete adversarial distribution where its ranking reverses relative to a simple decoding baseline.

### FE-063 — Evaluating defenders with stale attackers can materially understate vulnerability: GPT-Red reports an attacker-checkpoint × defender-checkpoint matrix with near-monotonic attacker improvement
**Status:** July 2026 primary OpenAI self-play study. This substantially advances the frozen-snapshot frontier but is **not** the exact requested protocol of training a separate held-out attacker from scratch against each frozen defender under identical budget.

Primary source:
- Wallace et al., *GPT-Red: Automated Red Teaming via Self-Play at Scale*, arXiv:2607.26115: https://arxiv.org/abs/2607.26115

Matrix evidence (Figure 6, instruction-hierarchy task; rows defender checkpoints 1→5, columns attacker checkpoints 1→5; ASR %):
- Defender 1: **67, 81, 79, 82, 78**
- Defender 2: **26, 27, 33, 44, 42**
- Defender 3: **24, 26, 28, 37, 32**
- Defender 4: **16, 19, 28, 25, 27**
- Defender 5: **12, 24, 20, 24, 29**
- The authors summarize that later attacker checkpoints are “nearly monotonically” better at breaking all defender checkpoints. For the final defender, using attacker checkpoint 1 would yield **12% ASR**, while attacker checkpoint 5 yields **29%**, more than double in this cell.
- Attacker-only training (not shown in the matrix) was reported to be narrower: better mainly against the defender trained against, worse on held-out defenders, and more prone to mode collapse. A separate nine-frozen-defender transfer matrix (Figure 7) also shows successful attacks found against one target do not always transfer to others.

Failure implication: defender progress cannot be safely evaluated with a fixed or stale red-team policy when attacker capability is also learnable. An old attacker can make a later defense look much stronger than a later adaptive attacker does. Scope guard: GPT-Red uses co-trained successive attacker checkpoints, not separately re-optimized-from-scratch held-out attackers per frozen defender snapshot, so the strict frontier remains open.

### FE-064 — Intent-drift-aware attacker training causally improves measured multi-turn attack success; removing intent alignment raises no-refusal behavior while reducing true harmful-success scoring
**Status:** ICLR 2026 primary ablation, directly relevant to the prior ADVERSA attacker-drift failure. It is an attacker-training ablation, not a paired replay of the same victim conversations.

Primary source:
- Feng et al., *SEMA: Simple yet Effective Learning for Multi-Turn Jailbreak Attacks*, arXiv:2602.06854 / ICLR 2026: https://arxiv.org/abs/2602.06854

Matched ablation evidence:
- Base attacker is fixed to Qwen2.5-3B-Instruct and training-time victim to Llama-3.2-3B-Instruct for the reward-design ablation; evaluation averages ASR@1 over Qwen2.5-3B-Instruct, Llama-3.1-8B-Instruct, and GPT-4.1-mini on AdvBench.
- Removing the intent-alignment component from the reward reduces LLM-classifier ASR@1 from **67.5% to 50.4% (-17.1 pp)** while **increasing the no-refusal rate**. The paper interprets the divergence as slight intent drift: prompts can avoid refusals without preserving the harmful objective.
- An extreme control that directly optimizes a no-refusal indicator learns benign queries (the paper gives “teach me how to write algorithms” as an example), producing **zero LLM-classifier success despite zero refusal**.
- A separate prefilling-self-tuning ablation finds that a Llama-3.2-3B-Instruct attacker without prefilling self-tuning consistently refuses to generate adversarial prompts and fails to converge; the prefilling-trained attacker learns stably.

Failure implication: red-team “pressure” is an endogenous property of attacker training. A high no-refusal rate is not sufficient evidence that a multi-turn attacker is preserving the target objective, and a drift-prone attacker can make a victim appear safer. This provides a matched intervention supporting FE-060’s infrastructure concern, while remaining scoped to SEMA’s open-loop attack construction, datasets, judges, and model choices.
