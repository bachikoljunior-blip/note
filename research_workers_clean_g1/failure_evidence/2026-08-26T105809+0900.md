### FE-079 — With the defender and held-out scenarios fixed, independently engineered attacker harnesses span 9.5% to 50.0% ASR
**Status:** primary arXiv preprint; AgentBeats Security Arena private-scoring rounds; held-out 21-scenario set.

Primary source:
- Jain et al., *Adaptive Adversaries: A Multi-Turn, Multi-LLM Benchmark for LLM Agent Security*, arXiv:2607.18063v1: https://arxiv.org/html/2607.18063v1

Evidence:
- The competition evaluated **21 independently submitted attacker teams** against a fixed released Baseline defender on **21 held-out scenarios**, two private-scoring rounds per submission (`N=42` battles/submission).
- Holding the defender fixed, submitted attackers produced **9.5% to 50.0% ASR**, median **29.3%**, across-submission standard deviation **11.1 percentage points**.
- The paper computes a worst-case per-submission binomial SE of about **7.7 pp** at `p=0.5`; the strongest and weakest attacker submissions have **non-overlapping 95% Wilson intervals**.
- Therefore the spread is not well explained by sampling noise alone. Attacker harness/search strategy is a material evaluation variable even when the defender, scenario set, backbone tier, and scoring rule are held fixed.

Failure implication: a safety evaluation that uses one fixed attacker harness can materially understate or overstate vulnerability relative to other independently developed attack strategies. The measured robustness number is partly a property of the red-team harness.

Scope guard: this does **not** show that the strongest competition submission approximates the true worst case, nor that the 9.5–50.0% range transfers to other models or domains. Harness code was not released, so exact compute/token budgets across teams are not matched.

### FE-080 — Removing response-conditioned adaptation collapses attack success from 30.0% to 0/36 in a paired small-scale ablation
**Status:** primary arXiv preprint; small targeted ablation on three high-ASR scenarios.

Primary source:
- Jain et al., arXiv:2607.18063v1, §5.3 and Appendix B.12: https://arxiv.org/html/2607.18063v1

Evidence:
- On three selected high-ASR scenarios (`codeapprove`, `memleak`, `smarthomejack`) across four `{Opus, GPT-5.4} × {Opus, GPT-5.4}` attacker/defender cells, the paper compares multi-round protocol variants at `N=3` runs per cell.
- The standard condition — **adaptive attacker + stateless defender** — averages **30.0% ASR** on this selected subset.
- Removing attacker access to prior defender responses while keeping the defender stateless yields **0/36 successful compromises**.
- Keeping attacker adaptation but making the defender stateful reduces ASR to **19.4%**.

Failure implication: repeated attempts alone are not equivalent to adaptive multi-turn pressure. If a benchmark permits multiple turns but re-samples attacks independently without response conditioning, it can miss a major failure channel in this tested setting.

Scope guard: this is a deliberately high-ASR three-scenario subset, only 108 battles overall, with `N=3` per condition/cell. The 30→0 contrast should not be generalized as an expected magnitude for all agent-security benchmarks.

### FE-081 — Fixed attack catalogs overfit public scenarios while adaptive-selection harnesses improve on held-out scenarios
**Status:** primary arXiv preprint; open competition public→private rank-shift analysis.

Primary source:
- Jain et al., arXiv:2607.18063v1, Appendix B.11: https://arxiv.org/html/2607.18063v1

Evidence:
- Teams optimized on **10 public scenarios** and were then ranked on **21 held-out scenarios**.
- Public-vs-private attacker rank correlation is only moderate: point Spearman `ρ=0.555`; bootstrap median **0.432**, 95% CI **[0.17, 0.66]**.
- Large fixed-catalog droppers include T18 **rank 5→20 (-15)**, T02 **3→11 (-8)**, T13 **7→14 (-7)**, T07 **15→21 (-6)**.
- Adaptive-selection risers include T06 **18→5 (+13)**, T19 **13→3 (+10)**, T21 **10→6 (+4)**, T08 **17→13 (+4)**.
- The paper attributes the qualitative split to whether the harness bakes in scenario-specific catalogs versus maintaining response-conditioned selection/refinement at evaluation time.

Failure implication: red-team quality measured only on visible/public attack scenarios can reward brittle scenario-specific catalogs that fail to generalize. Held-out evaluation can materially reorder attack harnesses.

Scope guard: the attribution uses anonymous team summaries rather than released executable harnesses, so this is competition-level observational evidence, not a randomized ablation of catalog-vs-adaptive design.

### FE-082 — The same guardrail/advisor stack can improve one operator model while worsening another under identical replayed attacks
**Status:** primary KDD-2026 workshop paper; NRT-Bench closed simulator; single-seed hosted-endpoint evaluation.

Primary source:
- Lee et al., *NRT-Bench: Benchmarking Multi-Turn Red-Teaming of LLM Operator Agents in Safety-Critical Control Rooms*, arXiv:2606.20408v3: https://arxiv.org/html/2606.20408v3

Evidence:
- NRT-Bench replays the **same recorded attack workload** under fixed cell configurations and scores objective simulator-derived critical-safety-function loss.
- Averaged across cells, enabling the full ten-layer guardrail stack changes ASR by **−6.9 pp** for `gpt-5.4-mini` but **+2.1 pp** for `claude-haiku-4-5`.
- In the matched `(S0, G10)` cell, toggling the safety advisor from off to on changes `gpt-5.4-mini` ASR **20.8%→1.4% (−19.4 pp)** but changes `claude-haiku-4-5` **33.3%→43.1% (+9.8 pp)** on the same payload workload and defense code.
- The authors explicitly caution that the largest single-cell magnitudes are from one seed and require repeated-seed confirmation.

Failure implication: a defense layer is an interface with the underlying operator model, not a model-independent patch. Reporting “guardrail X lowers ASR by k” without conditioning on the model/role stack can have the wrong sign for another operator family.

Scope guard: abstract textual simulator, hosted endpoints, one seed per operator, and the replay corpus is not a per-defender adaptive worst-case attack. This is strong matched sign-reversal evidence inside the tested grid, not a universal claim that guardrails hurt Claude-family systems.

### FE-083 — Round-1 scoring makes the same multi-round benchmark look almost safe while 15-round scoring exposes materially higher ASR
**Status:** primary arXiv preprint; same 21 scenarios, same attacker/defender models, same structured checks.

Primary source:
- Jain et al., arXiv:2607.18063v1, §5.3: https://arxiv.org/html/2607.18063v1

Evidence:
- On the same **21 scenarios** and the same **945-battle 3×3 attacker×defender matrix**, round-1-only scoring yields defender ASR **0.0% / 0.0% / 1.0%** for Opus / GPT-5.4 / Gemini.
- Scoring the full **15-round** interaction yields **5.4% / 5.4% / 14.0%**.
- Scenarios, attacker/defender identities, and structured success checks are unchanged; the relevant evaluation change is interaction budget and access to later adaptive turns.

Failure implication: single-turn or first-turn-only scoring can classify an agent-security setup as nearly robust even when the same systems fail under sustained interaction. Interaction budget is a first-class evaluation parameter.

Scope guard: later rounds also introduce more opportunities/samples, so the aggregate round-1→15 difference is not purely an adaptivity effect. FE-080 is the narrower ablation that separates response conditioning from repeated independent sampling on a small subset.
