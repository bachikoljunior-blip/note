## New failure evidence

### FE-252 — More context or more memory capacity does not solve supersession: bounded self-maintained memory can fail even when the model comprehends the same evidence in full context
**Primary source:**
- Patel, “Supersede: Diagnosing and Training the Memory-Update Gap in LLM Agents,” arXiv:2606.27472: https://arxiv.org/abs/2606.27472

On the knowledge-update subset of LongMemEval, a frontier GPT-5.4 setup reaches `92%` accuracy when the full conversational evidence remains in context, but only `77%` when it must rely on a bounded self-maintained memory (`paired McNemar p<0.005`). The gap persists across model scale while full-context performance saturates near `92%`, isolating memory maintenance from ordinary comprehension. Increasing available memory is not sufficient: when conversation length is scaled `24×`, accuracy falls from `68%` to `28%`; granting proportionally more memory leaves the result at `28%` (`n=25`).

A trainability positive control uses the Supersede environment to reward current-value answers and penalize stale ones. A Qwen2.5-3B GRPO run improves held-out supersession accuracy from `9.0%` to `16.7%` along a monotonic checkpoint curve, showing the failure is not necessarily fixed by architecture alone but can be targeted by a dedicated objective.

**Failure implication:** memory size and model reasoning capacity are not interchangeable with state-maintenance correctness. An agent can possess enough context to understand a revision yet fail when its own persistent summary must retire the superseded value. Evaluate update/retirement correctness directly rather than assuming a larger memory budget closes the gap.

**Scope guard:** the `28→28%` capacity control has `n=25`; the GRPO result is a single training run on a small open model. The study isolates one temporal fact-currency setting and does not imply all memory compression fails or that full context is viable at arbitrary horizons.

### FE-253 — Retrieval can succeed while the agent still answers from a superseded state; explicit supersession/dependency structure produces large gains under length-and-cost controls
**Primary source:**
- Fan et al., “Can Agent Memory Systems Track Evolving State?,” arXiv:2608.19652: https://arxiv.org/abs/2608.19652

StateMemBench contains `234` multi-session scenarios whose closed-pool grading distinguishes the currently valid state, a known superseded state, and other errors. Existing memory systems, retrieval baselines and long-context baselines struggle because the core problem is not merely retrieving relevant history but applying revision/supersession semantics. StateMem, which explicitly records supersession and relational dependencies, raises current-state accuracy on DeepSeek-V4-Flash from the strongest same-backbone baseline `0.205` to `0.363` (`1.8×`), and on Qwen3.5-9B from the strongest tested memory system `0.149` to `0.233` (`1.6×`).

The strongest causal-style control is the wrapper experiment: a lightweight state-structured transformation over six memory/retrieval backends raises StateMemBench current-state accuracy by `+32` to `+67` points; a length- and cost-matched control attributes `+15` to `+32` of those points specifically to state structure rather than extra context. The primary abstract also emphasizes that closed-pool grading isolates selection of stale state from generic failure.

**Failure implication:** “we retrieved the update” is not enough. Persistent agents need explicit rules for retirement, precedence, dependency invalidation and recomputation, and evaluations should distinguish stale-state reuse from retrieval miss or reasoning failure.

**Positive control / scope guard:** StateMem is a positive-control architecture on a synthetic/programmatic state-tracking benchmark plus standard memory benchmarks. Large wrapper gains need not transfer unchanged to free-form production tasks; structured traces/rules may themselves add reasoning cues beyond pure storage semantics, which is why the length/cost control is important but not a full component-by-component causal decomposition.
