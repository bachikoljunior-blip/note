## New claims

### FE-094 — Low static prompt-injection ASR can coexist with much higher adaptive ASR on the same defended agent/model stack
**Status:** primary June 2026 preprint full text; AgentDojo evaluation with deterministic model decoding.

Primary source:
- He et al., *Defending against Adaptive Prompt Injection Attacks via Reasoning-enabled Task Alignment*, arXiv:2606.15441: https://arxiv.org/abs/2606.15441

Evidence:
- On Qwen3-4B-Instruct-2507 in AgentDojo, the same defense implementations have much lower average held-out-static ASR than average six-attack adaptive ASR:
  - PIGuard: **3.33% static vs 33.8% adaptive**.
  - MELON: **3.86% vs 20.8%**.
  - MetaSecAlign: **3.52% vs 12.5%**.
  - PromptGuard: **10.3% vs 27.9%**.
- The paper reports temperature 0 for deterministic evaluation and defines the adaptive suite separately from the held-out static families.

Failure implication: a near-zero or single-digit static prompt-injection score is insufficient evidence that the same deployed defense remains robust once an attacker can optimize against it.

Scope guard: static and adaptive columns use different attack families/search procedures, so these are not paired per-prompt causal effects of “adaptivity alone.” The result is an evaluation-regime shift on the same model/defense/harness, not proof that every adaptive attacker creates the same multiplier.

### FE-095 — Adversarial training can look strong on held-out static attacks while leaving a material adaptive hole
**Status:** same primary RETA study; controlled component ablation on Qwen3-4B / AgentDojo.

Evidence:
- In the paper’s component ablation, a defender trained on Stage-I red-team examples (“Red-teaming Only”) reaches **4.19% held-out static ASR** but still has **17.5% Genetic adaptive ASR**, with attack-time user-task utility **51.2%** and benign utility **55.7%**.
- The full RETA pipeline, adding task-alignment reasoning plus multi-objective defender optimization, changes this joint profile to **2.90% static ASR, 7.50% adaptive ASR, 59.2% attack-time utility, and 60.8% benign utility**.
- A static-attacks-only training variant is worse still at **26.0% static ASR** and **50.0% adaptive ASR**.

Failure implication: “trained on adversarial examples” is not a sufficient robustness description. The strategy coverage and defender objective can materially change adaptive residual risk even when held-out static ASR already appears low.

Scope guard: this ablation changes more than one mechanism between “Red-teaming Only” and full RETA (task-alignment reasoning and multi-objective optimization), so the 17.5→7.5pp reduction cannot be uniquely attributed to one component. It is evidence about the tested pipeline combination, not a universal causal decomposition.

### FE-096 — Low attack success can be purchased by suppressing legitimate task completion, so ASR alone can reward brittle defenses
**Status:** same RETA primary table; same Qwen3-4B AgentDojo setting.

Evidence:
- Under held-out static attacks, PromptGuard reduces ASR from the undefended **33.3%** to **10.3%**, but user-task utility falls from **44.5%** to **25.5%**.
- PIGuard drives static ASR down to **3.33%**, while user-task utility is **33.8%**, still below the undefended **44.5%**.
- MetaSecAlign reaches a similar low ASR (**3.52%**) while raising user-task utility to **58.5%**, demonstrating that low ASR does not mechanically require the utility loss and serving as a positive control.

Failure implication: ranking prompt-injection defenses by ASR alone can favor defenses that block the attack partly by blocking legitimate work. Joint security/utility reporting is necessary to distinguish robust task alignment from broad suppression.

Scope guard: this comparison is on the paper’s AgentDojo held-out-static suite and its user-task-utility metric. It does not establish that PromptGuard or PIGuard always reduce utility in other configurations, thresholds, models, or deployments.

### FE-097 — A self-updating jailbreak-defense loop can itself become a high-leverage poisoning surface
**Status:** ICML 2026 Spotlight primary paper; official repository exists but full code release is still in progress as of this checkpoint.

Primary sources:
- Huang et al., *Rapid Poison: Practical Poisoning Attacks Against the Rapid Response Framework*, ICML 2026 / arXiv:2606.16242: https://arxiv.org/abs/2606.16242
- Official repository: https://github.com/DH-davidhuang/rapid-poison

Evidence:
- Rapid Response adapts a jailbreak detector by proliferating newly observed jailbreaks into synthetic variants and fine-tuning on them.
- The attack modifies only jailbreak samples: the threat model does **not** require attacker control over benign examples or labels.
- At only **1% poisoning rate**, the paper reports targeted poisoning reaching **up to 100% false-positive rate** and concept-backdoor poisoning reaching **up to 96% false-negative rate**.
- The authors’ mechanism is an omission attack: training on concept-absent unsafe examples can make the classifier spuriously associate the omitted concept with the safe label, allowing the trigger to suppress detection even for attack strategies the defender explicitly trained against.
- Reproducibility note: the official GitHub repository currently contains only `.gitignore`, `LICENSE`, and a short `README.md` stating “Code release in progress - full implementation and reproduction”; it does not yet expose the experimental implementation in the public main branch.

Failure implication: continual safety adaptation is not automatically monotonic. If untrusted incident/jailbreak material is amplified into future training data, the adaptation channel itself must be modeled as an adversarially writable surface.

Scope guard: the 100%/96% values are maxima over the paper’s tested poisoning objectives/classifier settings, not universal expected rates. The result targets Rapid-Response-style proliferation/fine-tuning pipelines under the paper’s threat model; it does not show that every online or continual-learning safety system is poisonable at 1%.
