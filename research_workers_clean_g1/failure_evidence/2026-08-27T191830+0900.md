## New failure evidence

### FE-249 — A memory policy can state the right commitment decision and still choose the wrong concrete tool action; prompting can reduce over-memory without fixing under-asking
**Primary source:**
- “Remember, Verify, or Ask? Cross-Family Evaluation of Memory Commitment in LLM Agents,” arXiv:2608.19564: https://arxiv.org/html/2608.19564

The Memory–Clarification Boundary benchmark uses independently adjudicated held-out cases where the correct action is one of `persist`, `ephemeral`, `verify world state`, or `clarify with the user`. The key distinction is source of truth: changing facts should be verified externally, while unresolved intent/scope can only be clarified with the user. On the 70-item held-out set, bare Qwen3.5-9B reaches `0.557` label accuracy with erroneous-persistence rate `0.243`, clarification recall `0.000`, and verification recall `0.667`. A policy prompt cuts erroneous persistence from `0.243` to `0.100` (Holm-adjusted `p=0.038`) but moves most uncertainty to world verification rather than user clarification; clarification recall rises only to `0.083`.

More importantly, stated label decisions do not reliably survive translation into structured actions. For Claude Sonnet 4.6, bare label accuracy is `0.814` but tool-call selection accuracy is `0.529` (`Δ=-0.286`, Holm-adjusted `p<0.001`), with only `57.1%` label–tool agreement. For Qwen, agreement is `22.9%` and accuracy falls from `0.557` to `0.343` (`Δ=-0.214`, `p=0.047`); its verification recall collapses from `0.667` to `0.056` in action mode. All tool arguments satisfy deterministic well-formedness rules, so the measured bottleneck is action selection, not malformed syntax.

**Failure implication:** memory governance cannot be validated only by asking the model what it *would* remember/verify/ask. The concrete commit/retrieve/check/clarify tool decision must be tested separately, and aggregate accuracy can hide safety-relevant shifts such as less erroneous persistence but persistent failure to ask the only authoritative source.

**Scope guard:** MCB-Act scores structured tool choice but does not execute the downstream memory/source/user interaction. The held-out cross-family set is 70 synthetic English cases, with one quantized Qwen checkpoint and pinned Claude versions; it establishes a label→action gap, not an end-to-end downstream utility estimate.

### FE-250 — Long-horizon personalized safety can remain near chance even when generic responses are safe; explicit risk-aware memory improves but does not justify context-independent safety testing
**Primary source:**
- An et al., “PerMemSafe: Benchmarking Implicit Personalized Safety of Long Horizon Self-Evolving Agents,” Findings of ACL 2026: https://aclanthology.org/2026.findings-acl.320/

PerMemSafe evaluates cases where a response that is generally acceptable becomes unsafe because safety-relevant user context has accumulated implicitly across long-horizon memory. The peer-reviewed ACL Findings paper reports that existing self-evolving agents show major limitations, with even the strongest tested system achieving only about `50%` personalized safety rate. SentinelMem, an active risk-aware memory framework that explicitly models personalized risk inference and memory evolution, improves implicit personalized safety by `23.8%` over prior memory frameworks while maintaining helpfulness in the tested long-horizon interactions.

**Failure implication:** evaluating a persistent agent only against context-independent safety prompts can miss hazards created by the interaction between old user-specific memory and a currently benign-looking request. Safety evaluation needs an evolving state/memory condition, not just the local utterance.

**Positive control / scope guard:** SentinelMem’s improvement shows that active risk-aware memory can help; the result is not evidence that personalization or persistent memory is intrinsically unsafe. The ~50% and +23.8% results are tied to PerMemSafe’s benchmark, models and memory frameworks and should not be extrapolated to population safety rates or arbitrary personalized agents.
