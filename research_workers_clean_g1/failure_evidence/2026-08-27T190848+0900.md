## New failure evidence

### FE-236 — Open-ended agent-as-verifier can confuse reachability/gameplay skill with correctness; direct state-grounded checks recover large verification accuracy
**Primary source:**
- Jia et al., “GameGen-Verifier: Parallel Keypoint-Based Verification for LLM-Generated Games via Runtime State Injection,” arXiv:2605.07442: https://arxiv.org/abs/2605.07442

Game correctness can depend on long-horizon state transitions that an open-ended gameplay verifier may never reach. GameGen-Verifier decomposes a natural-language specification into independent verifiable keypoints, patches the generated game runtime into the concrete state required by each keypoint, executes a bounded interaction, and checks the resulting state/assertion. On VeriGame (`100` generated games across `7` genres), the paper reports up to `92.2%` agreement with human judgments versus `58.8%` for the coverage-enforced Agent-as-a-Verifier baseline, while reducing wall-clock time by up to `16.6×`.

**Failure implication:** a verifier that must *navigate to* the state it wants to inspect measures a mixture of reachability, verifier policy competence and program correctness. For instrumentable environments, state injection/keypoint tests can separate “could not reach the state” from “state transition is actually wrong,” making false completion/correctness conclusions harder to hide behind long trajectories.

**Positive control / scope guard:** this is a white-box generated-game setting where runtime state is patchable; it does not establish that arbitrary production environments admit safe state injection or that all long-horizon verification can be reduced to local keypoints. Human agreement is the paper’s reference standard rather than a formal proof of game correctness.

### FE-237 — High outcome reward can coexist with near-chance latent-state recovery; optimizer strength can change state learning without reward-only evaluation revealing why
**Primary sources:**
- Allchin, “When Does Reward Teach State? A Hidden-Automaton Instrument and the Group-Language Boundary,” arXiv:2607.11953: https://arxiv.org/abs/2607.11953
- Full public article/reproducibility details: https://academ.us/article/2607.11953/

The study makes latent task state exactly observable to the evaluator by expressing tasks as hidden deterministic finite automata while never showing that state to the policy. In a 5-seed GRU optimizer×credit experiment, weak A2C can earn substantial normalized reward with almost no linearly recoverable state: on parity, `A2C×broadcast` reaches `0.66±0.04` normalized validation reward while the state-probe gap is only `+0.01±0.00`; on mod_3 it is `0.51±0.02` reward with probe gap `+0.02±0.01`. With the same task family but stronger PPO, `PPO×broadcast` reaches `0.79±0.14` reward / `+0.13±0.09` probe gap on parity and `0.96±0.08` / `+0.34±0.01` on mod_3. Under a fixed PPO budget as counter complexity increases, the fraction of achievable latent state recovered falls to `0.31` at `k=11`, while a privileged state auxiliary improves reward by `+0.43` there.

The paper further validates a one-directional structural warning signal on `153` fresh capacity-controlled automata: permutation/group-language structure predicts a perception gap at precision `0.86` (`89/103` cases where it fires). It also exhibits distinct perception and planning gaps: one task has state probe near chance (`+0.03`) with large reward gap, while another has high recoverable state (`+0.62`) but reward only `0.41`. Reward-only behavioral signals are therefore insufficient to tell whether the agent failed to represent state or represented it but failed to use it.

**Failure implication:** optimizing or auditing only scalar outcome reward can hide qualitatively different internal failures and choose the wrong remedy. For stateful workflows, independently measured state/progress probes or externally verifiable state invariants can distinguish missing representation from failed planning and reveal shortcut solutions that still earn reward.

**Positive control / scope guard:** the headline causal instrument is a small synthetic hidden-DFA laboratory (mostly ≤11 states), with a preliminary Qwen2.5-3B/7B port that does not yet establish the same clean perception-gap result at LLM scale. The group-language predictor is explicitly one-directional: absence of the warning does not imply safety. A privileged state auxiliary is diagnostic rather than deployable.
