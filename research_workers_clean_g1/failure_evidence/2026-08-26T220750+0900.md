## New claims

### FE-129 — Under an equal target-query cap, more privileged log-probability feedback need not yield the stronger jailbreak optimizer; proxy choice can reverse the expected information hierarchy
**Status:** October-2025 arXiv preprint; matched query-cap comparison in black-box jailbreak optimization.

Primary source:
- Zhang et al., *Black-box Optimization of LLM Outputs by Asking for Directions*, arXiv:2510.16794v1 (19 Oct 2025), Table 3.

Evidence:
- The jailbreak comparison fixes the maximum target-query budget at 200 and re-runs a log-probability-based optimization baseline with model-specific initialized adversarial suffix templates for a fair comparison.
- On GPT-4.1-mini, the log-probability optimizer reaches `56%` ASR while the text-only comparative-feedback optimizer reaches `98%` ASR, despite the latter not receiving target token probabilities.
- On Llama-3.1-8B, Llama-3.1-70B, and GPT-4 Turbo, both methods reach `100%` ASR under the same 200-query cap; the text-only method reports mean queries `32.4`, `15.2`, and `6.1` respectively.
- The authors attribute the GPT-4.1-mini gap in part to the log-probability baseline directly optimizing an affirmative-response token such as “Sure,” which may itself interact with defenses, whereas the text-only method uses relative response comparisons rather than that proxy.
- A separate prompt-injection table is directionally consistent rather than universal: text-only exceeds log-probability optimization on Llama-3.1-70B (`75.0%` vs `61.4%`) and GPT-4o-mini (`87.5%` vs `85.7%`), while GPT-4o is nearly tied in the opposite direction (`75.0%` vs `76.8%`).

Failure implication: attack strength cannot be ordered solely by how much privileged feedback the attacker receives. A richer feedback channel can underperform when its optimization proxy is misaligned with substantive attack success or interacts with defenses. Red-team comparisons should therefore match query budget and validate the attack objective, rather than assuming log-probability access dominates text-only feedback.

Scope guard: this is not a single-factor “feedback channel only” causal ablation—the compared optimizers use different objectives/updates—and it does not show that text-only feedback is generally stronger than log probabilities. It shows a concrete equal-query setting in which the expected information hierarchy fails.

### FE-130 — With the optimizer and target fixed, attacker initialization can materially change both observed ASR and search cost
**Status:** same October-2025 primary source; suffix-initialization ablation.

Primary source:
- Zhang et al., arXiv:2510.16794v1, Table 5.

Evidence:
- On Claude Sonnet 3.5, the same text-only optimizer initialized from a strong jailbreak template reaches `100%` ASR with `12.5` mean queries, while random-suffix initialization reaches `78%` ASR with `27.9` mean queries.
- On Llama-3.1-70B, both initializations reach `100%` ASR, but the strong-template run uses `15.2` mean queries versus `16.6` for random initialization.
- Thus, on one tested target, changing only the initialization regime shifts terminal ASR by `22` percentage points and more than doubles mean query cost.

Failure implication: a single attacker initialization can understate or overstate defender robustness even when the attack algorithm is otherwise unchanged. Robust red-team evaluation should use multiple independently initialized or template-diverse restarts and report attacker-search variance/cost, not only best terminal ASR.

Scope guard: the table contains two target models and compares strong-template versus random-suffix initialization; it is not a multi-seed stochastic-variance study. The 22-point effect is specific to Claude Sonnet 3.5 under this optimizer/setup.

### FE-131 — Generating fresh stochastic attack sequences separately for each defender confounds defender robustness with attacker luck; paired replay is needed for record-level attribution
**Status:** July-2026 arXiv v3; explicit protocol comparison in a multi-turn operator-agent benchmark.

Primary source:
- Lee et al., *NRT-Bench: Benchmarking Multi-Turn Red-Teaming of LLM Operator Agents in Safety-Critical Control Rooms*, arXiv:2606.20408v3 (6 Jul 2026), Sections 4.3 and 5.4, Tables 4–5.

Evidence:
- In the full eight-cell grid, each operator is attacked by independent stochastic generations from the same strategy catalog. The authors explicitly state that these per-cell rates mix two effects: operator robustness and the attacker’s luck against that operator.
- To isolate operator effects, the benchmark defines a paired-replay split of 149 recorded attacker payload sequences. Every operator receives the same payload sequences in the same order under matched cell labels, so per-record differences are attributable to the operator/defense configuration rather than a newly sampled attacker sequence.
- On this fixed corpus, aggregate paired ASR is GPT-5.4-mini `11.4%`, Claude-Haiku-4-5 `8.7%`, Gemma-4-26B `12.1%`, and Qwen3.5-35B `11.4%`.
- The independently generated full-grid aggregates are not record-comparable and yield materially different nominal values; for example GPT-5.4-mini is `23.7%` and Claude-Haiku-4-5 is `37.5%` there. The paper cautions that the fresh-generation grid and paired replay answer different questions.

Failure implication: comparing defenders using independently sampled adaptive/stochastic attacks can turn attacker-sampling variation into an apparent model difference. For causal attribution of defender differences, a fixed replay corpus is an important control; for worst-case exploitability, fresh per-defender best responses are still required. These are complementary evaluation protocols rather than substitutes.

Scope guard: the change in nominal GPT-versus-Claude ordering between the full grid and paired replay is not claimed as a causal reversal caused solely by attacker luck, because the paired 149-session split is a curated subset rather than the identical full-grid records. The strong claim is the benchmark authors’ explicit confounding diagnosis and the record-level comparability provided by paired replay.
