### FE-047 — A defense-specific black-box adaptive attack converts several apparently robust static-defense results into high attack-success regimes
**Status:** peer-reviewed ACL 2026 primary source; matched platform/backend/default-defense settings across attack types, but LLM-as-judge is used for ASR and is not perfect.

Primary source: Geng et al., *PIArena: A Platform for Prompt Injection Evaluation*, ACL 2026, https://aclanthology.org/2026.acl-long.1533/

Matched evidence (Table 2 averages across the tested task suite; Qwen3-4B-Instruct backend, default defense settings):
- PISanitizer: ASR **0.04 Combined / 0.11 Direct -> 0.86 Strategy**.
- SecAlign++: **0.07 / 0.04 -> 0.21 Strategy**, while no-attack utility is only **0.58** vs **0.74** no-defense.
- PromptGuard: **0.25 / 0.30 -> 0.92 Strategy**.
- PIGuard: **0.22 / 0.27 -> 0.79 Strategy**.
- DataSentinel: **0.12 / 0.26 -> 0.45 Strategy**.
- AttentionTracker is the bounded positive control: strategy ASR remains **0.01**, but its average no-attack utility is only **0.15**.
- The adaptive attack uses 10 semantic rewriting strategies and defense feedback; on Dolly Closed QA most defenses are bypassed in ~1–2 refinement iterations on average, with SecAlign++ requiring 4.555.

Failure implication: a defense can look robust under static or direct prompt corpora yet fail under inexpensive defense-conditioned black-box refinement. Static ASR is not a robust lower bound on adaptive ASR. Scope is the PIArena task suite, its judge, default implementations, and attack model; it does not prove every adaptive attacker will achieve the same ASR.

### FE-048 — Short adaptive campaigns materially understate worst-case prompt-leak severity; several defenses fail only after tens to hundreds of rounds
**Status:** April 2026 preprint primary source; direct repeated interaction with fixed defense configurations, deterministic exact/phrase leak scoring; safety filters disabled in primary defense comparison.

Primary source: Deep et al., *Evaluation of Prompt Injection Defenses in Large Language Models*, arXiv:2604.23887, https://arxiv.org/abs/2604.23887

Matched evidence:
- Each defense initially receives a 25-round campaign (250 attacks). Output filtering and multi-layer-with-output-filter show no leak; other defenses show only small/partial leaks.
- Extending the same adaptive campaign until critical leak (`score >= 0.9`) or 500 rounds changes the conclusion for every model-reliant defense.
- Reported rounds to critical leak: input sanitization **39**, security directives **49**, delimiter **84**, instruction hierarchy **247**, sandwich defense **277**.
- Sandwich defense specifically changes from **0.4% leak rate / worst severity 0.05** in the 25-round run to **3.8% leak rate / worst severity 0.95** by the 277-round campaign.
- Output filtering is a bounded positive control: output-filter-only and multi-layer-with-filter each survive three independent 500-round runs, totaling 15,000 attacks, with zero exact-match leaks under this scoring rule.

Failure implication: short red-team windows can miss long probing phases followed by abrupt breakthrough, so “no critical failure in N attacks” is highly horizon-dependent. The positive control also prevents overclaiming that all defenses inevitably fail: deterministic output filtering held for the finite tested secret-leak objective, although the paper notes substring filtering can miss fuzzy/encoded leakage.

### FE-049 — The same prompt-injection defense can reduce ASR sharply on one model and increase it on another; intervention implicates tool-use re-exposure
**Status:** June 2026 preprint/Zenodo primary record, factorial AgentDojo evaluation; not peer-reviewed in the source record.

Primary source: Singh & Mittal, *When Defenses Backfire: Model-Dependent Failure Modes in Prompt-Injection Defense for LLM Agents*, Zenodo DOI 10.5281/zenodo.20735484, https://zenodo.org/records/20735484

Matched evidence from the author record:
- Factorial evaluation: five production LLMs x four task suites x three defenses x four attacks = **240 conditions** on AgentDojo.
- Under the **same static attack**, a defense can lower one model's ASR by as much as **86.7 percentage points** while increasing another model's ASR by **31.2 pp**.
- Across attackable models, defense-induced change in tool-use activity correlates with backfire at **r=0.72**.
- An external tool-budget cap monotonically removes the largest backfire effect, which the authors use as an intervention isolating repeated exposure to malicious observations as the mechanism.
- Some conditions are strictly dominated: defense raises ASR while lowering utility.

Failure implication: “adding a defense cannot hurt” is false in the tested agent setting, and defense safety is model-dependent. This is distinct from adaptive-attacker collapse because the attack is held static; the tested failure arises from the defense changing the agent's interaction trajectory/exposure. Treat as preprint evidence until independently replicated.

### FE-050 — Sustained white-box red-teaming of successive stateful-monitor versions found failure modes that directly changed the final monitor algorithm
**Status:** arXiv primary source with large red-team volume; successive-version exercise is real, but the paper does **not** publish a version-by-version matched ASR curve, so this only partially satisfies the per-snapshot frontier.

Primary source: Brown et al., *Stateful Online Monitoring Catches Distributed Agent Attacks*, arXiv:2605.31593, https://arxiv.org/abs/2605.31593

Evidence:
- Six red-teamers attacked **successive versions** of the monitor over two months, producing **>100,000 attacks across 2,985 sessions and 1,159 user IDs** with white-box access to cluster assignments and suspiciousness scores.
- Red-teaming exposed two concrete stateful-monitor failure modes: (1) renaming files/paths or changing vocabulary could split one distributed attack across nearby embedding clusters and delay review; (2) ambiguous suspicious examples could persist in cluster memory and drive high false-positive rates.
- These failures changed the final algorithm: assign to a set of related clusters instead of one centroid, and deduplicate/sort cluster memory before assembling top-k evidence.
- Final reported positive controls include 81.1–87.2% campaign recall at 2.35–3.09% benign-conversation FPR with 10x background vs 75.0% recall at 2.72% FPR for the matched standard monitor; the defense catches monitor-context poisoning in **528/644 sessions (82%)** and sequential decomposition in **29/29**.

Failure implication: a large, realistic defense can require iterative attack-driven algorithm redesign; pre-red-team architecture can have structural weaknesses not visible in its nominal benchmark. However, because exact success metrics per successive version are not published, this is **not** the fully matched “re-optimize separately against each frozen snapshot and plot ASR per snapshot” evidence sought by the frontier.

### FE-051 — Prompt-attack defense fine-tuning can learn surface shortcuts that cause large benign false refusals and out-of-distribution utility loss
**Status:** peer-reviewed ACL 2026 primary source; controlled diagnostics across two base models and multiple defense pipelines, distinct from HASTE's single-detector hard-negative result.

Primary source: Li et al., *Defenses Against Prompt Attacks Learn Surface Heuristics*, ACL 2026, https://aclanthology.org/2026.acl-long.502/

Reported controlled diagnostics:
- Position bias: moving benign task content to the suffix increases rejection from **below 10% to as high as 90%** across reasoning benchmarks.
- Token-trigger bias: inserting a single token common in attack data increases false refusals by **up to 50%** even in benign contexts.
- Topic-generalization bias: defended models show test-time accuracy drops of **up to 40%** outside the defense-training topic distribution.
- The study spans **two base models and multiple defense pipelines**.

Failure implication: high attack rejection can be achieved by shortcut learning rather than intent recognition, creating hidden utility regressions under harmless positional/token/topic shifts. This is not a direct replication of HASTE FE-045's category regressions, but it is independent, multi-pipeline evidence for the broader failure mode “aggregate defense success can conceal distribution-specific regressions.”
