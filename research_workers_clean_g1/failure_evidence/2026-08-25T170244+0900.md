### FE-001 — Intrinsic self-correction can degrade reasoning without external feedback

Primary source: Huang et al., “Large Language Models Cannot Self-Correct Reasoning Yet,” ICLR 2024.
- https://proceedings.iclr.cc/paper_files/paper/2024/file/8b4add8b0aa8749d80a34ca5d941c355-Paper-Conference.pdf
- https://openreview.net/forum?id=IkmD3fKBPQ

Matched setup / tested scope:
- Reasoning benchmarks GSM8K, CommonSenseQA, HotpotQA; GPT-3.5/GPT-4 plus additional GPT-4-Turbo/Llama-2 experiments.
- Intrinsic self-correction = feedback/refinement without oracle answer-correctness labels.

Quantitative failure evidence:
- GPT-3.5 GSM8K: standard 75.9%; after round 1 75.1%; round 2 74.7%.
- GPT-3.5 CommonSenseQA: 75.8% → 38.1% → 41.8%.
- GPT-4 GSM8K: 95.5% → 91.5% → 89.0%.
- GPT-4 HotpotQA: 49.0% → 49.0% → 43.0%.
- GPT-4-Turbo GSM8K: 91.5% → 88.0% → 90.0%.
- Llama-2 GSM8K: 62.0% → 43.5% → 36.5%.
- Llama-2 CommonSenseQA: 64.0% → 37.5% → 36.5%.
- On GPT-3.5 GSM8K after two rounds, incorrect→correct changes were 7.6% while correct→incorrect changes were 8.8%.

Matched positive control:
- With oracle labels used to stop correction, GPT-3.5 GSM8K rose 75.9%→84.3%, GPT-4 HotpotQA 49.0%→59.0%; the paper argues those gains require external correctness information.

Scope limit:
- This is evidence against intrinsic prompted self-correction in these tested models/tasks/prompts, not against correction with reliable external verifiers, trained critics, or newer specialized reasoning systems.

### FE-002 — Multi-agent debate did not beat equal-response self-consistency in the replicated GSM8K setup

Same primary source: Huang et al., ICLR 2024, Table 7 / Section 4.

Matched setup / tested scope:
- gpt-3.5-turbo-0301, GSM8K full test set, 3 agents, 2 debate rounds; exact prompt from Du et al. replication; comparison controls total response count.

Quantitative failure evidence:
- 6 responses: multi-agent debate round 1 = 83.2%; self-consistency = 85.3%.
- 9 responses: multi-agent debate round 2 = 83.0%; self-consistency = 88.2%.
- Standard prompting 1 response = 76.7%; self-consistency 3 responses = 82.5%.

Interpretation constrained to evidence:
- In this setup, the extra interactive debate structure did not outperform a simpler majority-vote sampling baseline at equal response budget.

Scope limit:
- Does not establish that all heterogeneous or specialized multi-agent systems fail; tested system used multiple instances of one ChatGPT-family model on GSM8K.

### FE-003 — Search-time contamination can inflate search-agent benchmark scores

Primary sources:
- Han et al., “Search-Time Data Contamination,” arXiv 2508.13180 (2025): https://arxiv.org/abs/2508.13180
- Wang et al., “Search-Time Contamination in Deep Research Agents: Measuring Performance Inflation in Public Benchmark Evaluation,” arXiv 2606.05241 (2026): https://arxiv.org/abs/2606.05241

Matched / ablation evidence:
- Han et al. report that on HLE, SimpleQA, and GPQA, search-based agents directly found benchmark datasets with ground-truth labels for about 3% of questions; blocking HuggingFace caused about a 15% accuracy drop on the contaminated subset.
- Wang et al. evaluate modern deep-research agents across six public benchmarks and report search-time contamination inflating measured performance by up to 4%.
- Their manual MedQA sample reports explicit answer leakage for 60% of 100 Gemini Deep Research questions; Valyu had 0% leakage on MedQA but 78% on PubMedQA, indicating leakage depends on retrieval infrastructure and benchmark/source overlap.

Scope limit:
- Inflation estimates apply to public benchmarks accessible through the tested web/retrieval environment. They do not imply the same leakage rate for private/dynamic tests or isolated sandboxes.

### FE-004 — Reusable “agent skills” can cause both functional and efficiency regressions under paired comparisons

Primary preprint:
- Dong et al., “Agent Skills Can Be Harmful: An Empirical Study of Skill-Induced Failures in LLM Agents,” arXiv 2608.11888 (2026): https://arxiv.org/abs/2608.11888

Matched setup / tested scope:
- Differential analysis compares a target skill-guided run with a no-skill or semantically matched reference run that solves the same task, or solves it more cheaply, on SkillsBench and SWE-Skills-Bench.

Quantitative failure evidence:
- 307 skill-induced failures identified: 125 functional failures and 182 efficiency regressions.
- Within “Excessive Procedure,” excessive verification contributed 67 cases and heavy implementation pipelines 30 cases.
- Authors report efficiency regressions are not explained by prompt length alone.

Scope limit:
- Very recent preprint; evidence is benchmark- and implementation-specific and should not be generalized to every skill system. The paired-counterfactual design is nevertheless directly relevant as a methodology for attributing regressions.

### FE-005 — Partial traces substantially reduce failure-attribution accuracy in multi-agent systems

Peer-reviewed primary source:
- Chen et al., “Seeing the Whole Elephant: A Benchmark for Failure Attribution in LLM-based Multi-Agent Systems,” ACL 2026: https://aclanthology.org/2026.acl-long.912/

Matched setup / tested scope:
- TraceElephant compares attribution under full execution traces versus a partial-observation counterpart over reproducible multi-agent environments.

Quantitative evidence:
- Full traces improve failure-attribution accuracy by up to 76.5% over partial observation.

Failure implication:
- Output-only/partial traces can obscure the responsible agent or decisive step, so failure diagnoses based only on final outputs/inter-agent outputs may be materially wrong.

Scope limit:
- This is failure-attribution evidence, not direct evidence that full traces improve task success.

### FE-006 — Benchmark defects can masquerade as agent failures

Primary preprint:
- Tu et al., “BenchGuard: Who Guards the Benchmarks? Automated Auditing of LLM Agent Benchmarks,” arXiv 2604.24955 (2026): https://arxiv.org/abs/2604.24955

Quantitative evidence:
- BenchGuard identified 12 author-confirmed issues in ScienceAgentBench, including fatal errors making some tasks unsolvable.
- On BIXBench Verified-50, it exactly matched 83.3% of expert-identified issues.

Scope limit:
- Evidence is about two scientific-agent benchmarks and an automated auditor; do not infer that a particular failure on another benchmark is benchmark-caused without task-level audit.
