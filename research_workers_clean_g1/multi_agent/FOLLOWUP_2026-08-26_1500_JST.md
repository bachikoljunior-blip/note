## C73 — uncertainty-targeted probing is better targeted than fixed epsilon, but does not yet improve endpoint quality reliably

This is a **role-local synthetic experiment**, not an external empirical claim. It preserves the C68–C72 simulator family: 16 cells, 1,200 evaluator-call budget, `rho_A=rho_B=.6`, three A calls before escalation, up to four B calls, and the same proposal/evaluator likelihood model.

The new controller adds a small uncertainty model around the online fresh-proposal opportunity estimate. It keeps count/mean/variance for 10 incumbent bins plus cell×bin local statistics. A 95% approximate interval is formed around the opportunity estimate. `target05` forces an A-only probe with probability 0.05 **only when that interval crosses the current first-step B-EVSI decision boundary**. `eps05` forces the same nominal 5% probe probability before A evidence, regardless of decision relevance. Both continue to learn from naturally A-only pipelines as well as forced probes. The interval is a controller heuristic, not a calibrated confidence guarantee.

The main comparison used 150 paired seeds per condition. Values below are mean final archive quality; `±` is the paired 95% half-width versus the `oracle64` routing baseline. `target−eps` is also paired and every listed interval contains zero.

The conservative result is **negative**: at this horizon and probe rate, uncertainty-targeted probing did not establish an endpoint-quality advantage over either no-probe learning or fixed 5% probing. It also did not establish harm; all targeted-vs-fixed quality intervals span zero.

There is nevertheless a useful routing signal. In the asymmetric regimes, targeted probing reduced the oracle-relative routing-regret proxy versus fixed epsilon while using fewer probes:

- `cross=0.0`: fixed `0.000629`, targeted `0.000512`.
- `cross=0.5`: fixed `0.000667`, targeted `0.000513`.
- `cross=1.0`: fixed `0.000752`, targeted `0.000619`.

The targeted controller also used slightly more B calls than fixed epsilon in those regimes (`141.1 vs 137.0`, `125.7 vs 123.4`, `114.1 vs 111.1`), so the lower routing-regret proxy has not yet translated into a better end-to-end budget allocation. In the weak symmetric regimes the routing-regret differences were small or mixed.

A higher 10% targeted-probe pilot and a probe-every-uncertain-state pilot were also run before the control-freeze stop. They generated many more forced A-only decisions and did not show a stable endpoint advantage. This is consistent with the earlier C70 lesson: **uncertainty alone is not the value of acquiring information**.

The low-incumbent calibration target remains unresolved in this physical invocation. States below incumbent 0.2 were too sparse for the simple per-run audit used in the pilot to yield a stable aggregate estimate. This is itself compatible with C69's warning: the states with highest marginal exploration value can be rare under the late-run visitation distribution, so endpoint quality can hide calibration defects.

## C74 — fresh 2026 evidence reinforces that observation/query cost belongs inside the objective, not behind an uncertainty threshold

Three fresh public sources sharpen the interpretation without validating the synthetic numbers directly:

1. Schur, Lago & Fiez, **“The Price of Knowledge: Optimal Algorithms for Costly Bandits”**, UAI 2026. The objective explicitly combines reward regret with the cost of requested observations, and the theory introduces cost-adjusted information-gain quantities rather than treating every uncertain state as worth observing. https://proceedings.mlr.press/v337/schur26a.html
2. Reyzin, Saha & Wu, **“Expert Advice with Costly Observations”**, UAI 2026. The optimal observation budget depends jointly on horizon, number of experts, gaps, and heterogeneous query costs; more queried experts are not monotonically better. https://proceedings.mlr.press/v337/reyzin26a.html
3. Liu et al., **“LENS: Latent Precision Inference in Multi-LLM Routing”**, UAI 2026. Selective logging, imperfect evaluation signals, and temporal drift make interaction feedback variably precise; LENS explicitly models latent precision rather than weighting all feedback equally. https://proceedings.mlr.press/v337/liu26b.html

These are bandit/routing results, not QD archive experiments. The narrow transferable principle is that **query uncertainty, query cost, and feedback precision must be modeled separately**.

## Controller implication

The C73 negative result narrows the controller hypothesis. The next controller should not use

`probe iff opportunity-confidence interval crosses EVSI_B`

as the full rule. Crossing the boundary identifies a potentially decision-sensitive state, but does not price the immediate loss from withholding B, the expected reduction in *future* routing error from the new opportunity label, or the label's effective precision.

A stronger rule is closer to:

`probe iff expected future routing-regret reduction from opportunity-model update > immediate decision loss + displaced evaluator/proposal value + controller cost`.

This turns opportunity probing itself into a costly-information problem. The key quantity is **value of information about the opportunity model**, not raw uncertainty width.

## Scope and limitations

- C73 is synthetic and does not measure real LLM judges, real agent teams, or a real QD archive.
- The confidence interval is heuristic and uses empirical/shrinkage variance; no coverage theorem is claimed.
- Fixed and targeted probes alter the random execution path and therefore are paired by seed but not by a pre-materialized common-randomness event log.
- The online learner still consumes policy-selected natural A-only labels, so selection bias remains.
- `cross_mix` is a simulator parameter, not a calibrated real judge-correlation coefficient.
- The public UAI 2026 results support cost/precision-aware observation in their own settings only; they do not establish the synthetic archive effects.
- No stable low-incumbent calibration estimate was obtained in this invocation.

## Frontier (nonempty)

1. Replace boundary-crossing probing with an explicit **opportunity-model VoI controller**: estimate how one A-only label would change future B-routing decisions over a short horizon and query only when that expected improvement exceeds immediate opportunity cost.
2. Compare myopic VoI, Thompson-style sampling, UCB-style optimistic opportunity cost, and no-probe learning under the same 1,200-call budget.
3. Build a pre-materialized common-randomness event stream so probe/routing policies can be compared with lower paired variance despite different call paths.
4. Add state-coverage diagnostics: deliberately track rare low-incumbent cells and measure calibration error conditional on visitation, not only endpoint quality.
5. Add nonstationarity: shift proposal quality or evaluator precision mid-run and compare cumulative, sliding-window, and latent-precision learners.
6. Move to a real repeated-judge dataset with human labels and per-call cost once a suitable public dataset is identified; retain false-admit/false-reject and error-correlation separation.
