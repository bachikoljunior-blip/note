### A = GPT-5.4-mini, B = GPT-5.4, target = observed human expert preference
On the 30-item spread sample:
- mini agreement with the observed human preference: `19/30 = 0.6333`
- GPT-5.4 agreement: `17/30 = 0.5667`
- mini wrong relative to the human observation: `11`
- among those 11, GPT-5.4 corrected `2`: `p_help = 0.1818`; Jeffreys 95% interval approximately `[0.0398, 0.4672]`
- mini correct relative to the human observation: `19`
- among those 19, GPT-5.4 flipped `4` to the human-disagreeing answer: `p_harm = 0.2105`; Jeffreys 95% interval approximately `[0.0755, 0.4262]`
- the two model judges disagreed on 6 items; mini matched the human on `4/6`, GPT-5.4 on `2/6`.

Thus this sample provides **negative evidence against a naive `mini uncertain -> call the nominally larger judge and adopt it` escalation rule**. The point estimate of residual help is not larger than residual harm, and credible intervals are wide. This is not evidence that GPT-5.4 is globally worse; it is evidence that model name/size is not a valid substitute for slice-conditioned residual-value calibration.

### Reference-target sensitivity: intended constructed ordering vs one expert observation
JudgmentBench intentionally includes both a constructed quality order and individual human preferences, so the same 30 items expose a key controller issue: the residual value depends on the target claim.

Using the constructed higher-quality level as the benchmark target:
- GPT-5.4-mini: `24/30 = 0.8000`
- GPT-5.4: `20/30 = 0.6667`
- observed human preference matches constructed ordering: `23/30 = 0.7667`
- mini wrong: `6`; GPT-5.4 repairs `1` -> `p_help = 0.1667`, Jeffreys 95% approx `[0.0186, 0.5581]`
- mini correct: `24`; GPT-5.4 harms `5` -> `p_harm = 0.2083`, Jeffreys 95% approx `[0.0843, 0.3980]`
- on the six model-model disagreements, mini matches constructed ordering `5/6`, GPT-5.4 `1/6`.

The qualitative conclusion is the same in this sample, but the absolute accuracy changes materially depending on whether the target is *one expert's holistic preference* or *the benchmark's intended constructed order*. Therefore a semantic-correction controller must bind its calibration to a **specific target construct/reference**, not merely `correctness`.

### Difficulty proxy: adjacent vs two-level quality gap
The sample contains 20 adjacent-level comparisons (`gap=1`) and 10 intermediate-vs-excellent comparisons (`gap=2`). This is only a small exploratory slice.

Against observed human preference:
- gap 1: mini `0.70`, GPT-5.4 `0.60`; models disagree on 6/20; mini wins those disagreements 4 vs 2.
- gap 2: both models choose identically on all 10, yet match the observed human preference only `5/10`.

Against constructed ordering:
- gap 1: mini `0.80`, GPT-5.4 `0.60`.
- gap 2: both `0.80`, and they agree on all 10.

The gap-2 subset is a compact reminder that **model-model agreement can be high while the relation to an expert observation remains uncertain**. Because there is only one observed human preference per assignment here, this cannot distinguish stable model error from expert-label noise/disagreement. It therefore strengthens the requirement for reference-target qualification, not a claim of judge failure.

## Controller update
Refine the semantic-correction gate to:
1. `target_claim / construct identity` must be explicit (e.g. expert preference vs intended quality order vs factual correctness).
2. verify construct applicability and sensitivity.
3. estimate `p_help = P(B helps | A wrong, same target, supported slice)` and `p_harm = P(B harms | A correct, same target, supported slice)` with credible bounds.
4. do not escalate merely because A and B disagree, and do not use nominal model strength as a proxy for residual value.
5. scale destructive-promotion evidence by an explicit repair-risk vector / blast radius.
6. if residual value is unsupported or net utility is not credibly positive, keep `zero-extra-call abstain/provisional` as an explicit competitor.
7. only after semantic promotion, run the separate repair-admissibility gate (dependency closure, authority, external effects, serving state).

## Scope and negative-result discipline
- The 30-item sample is deterministic and spread across the file but not random, not preregistered, and not a held-out test.
- Human preference is an expert observation, not objective ground truth. The benchmark itself is explicitly judgment-rich.
- The constructed quality order is an intended benchmark target, not proof that every individual higher-level output is semantically superior.
- Credible intervals are wide; no operational threshold is inferred.
- No claim is made that GPT-5.4 is globally worse than GPT-5.4-mini.
- The useful result is architectural: **residual verifier value must be measured on the target construct and target slice; agreement/model identity is insufficient.**
