## Public-source sharpening: four evidence layers should not be collapsed

### 1. Receipt/history integrity

SCITT AI-Agent Action Receipt draft-01 (2026-08-15) explicitly separates artifact validity from sufficiency. It states that a signed action receipt records what a governed boundary recorded, not that inputs were complete, a named person authorized the exact action, a downstream controller succeeded, or a physical effect occurred. Tail truncation requires an authenticated checkpoint; Transparency Service registration alone still does not give offline non-equivocation without consistency proofs and monitoring.

Primary source:
`https://www.ietf.org/ietf-ftp/internet-drafts/draft-noa-scitt-ai-agent-receipt-01.html`

The same draft now makes the division of labour explicit:
- the receipt says what the governed boundary recorded;
- an action digest binds later artifacts to the same action projection;
- an independent witness says what an outside system observed.

### 2. Per-action authorization state

AADP draft-01 (2026-08-20) separates standing capability from whether **this action with these arguments may execute now**, given mutable budgets, reservations, approval lifecycle and kill switch. It also distinguishes at-most-once permit consumption, exactly-once decision/report state, and exactly-once external effect; the last cannot be guaranteed by AADP alone. If an external effect is unknown after failure, the PEP must not blindly re-issue it.

Primary source:
`https://bio-test.nic.funet.fi/pub/netinfo/internet-drafts/draft-saha-aadp-01.html`

### 3. Action correlation/binding

NOA Action Digest draft-01 (2026-08-14) derives a correlation value from a verified authorization record, parameter commitment, execution grant and single-use nonce. The draft is explicit that digest equality proves **correlation only**; it is not proof that the action executed or an effect occurred.

Primary source:
`https://rsync.nic.funet.fi/pub/doc/netinfo/internet-drafts/draft-toraman-noa-action-digest-01.html`

### 4. Physical-effect evidence

NOA Settlement Evidence draft-01 (2026-08-14) is a separate signed side artifact for observed payment effects. This reinforces that a recovery certificate should not collapse `record valid`, `authorized now`, `same action`, and `effect observed/reconciled` into one generic receipt bit.

Primary source:
`https://www.ietf.org/archive/id/draft-toraman-noa-settlement-evidence-01.html`

## Exact execution-edit evidence remains compatible

The new public paper `When Can Agents Safely Checkpoint, Fork, Restore, and Merge? Exact Checking for Execution Edits` (arXiv:2608.22928, submitted 2026-08-24) states that an edit cannot undo earlier authorization or a tool request already sent; exact safety therefore depends on past actions, still-required results, and calls that began before the edit. This continues to support keeping authorization/result/progress evidence outside pure dependency-graph completeness.

## Scope / negative evidence

- The finite model is synthetic and assumes positive evidence bits are truthful; it does not model forged attestations, colluding issuers, buggy verifiers or hidden unmediated channels that falsely issue completeness proof.
- `15,364/131,072` is a count over an artificial Boolean cube, not an incident rate.
- A directly trusted live head proves only the scoped current-transaction history claim. It must never be reused as global anti-equivocation proof.
- Conversely, a transparency inclusion proof is not by itself proof of transaction freshness, authorization, capture completeness, or physical effect.
- AADP and the NOA/SCITT documents are Internet-Drafts/work in progress; they sharpen evidence boundaries but are not deployment certification.
- The exact execution-edit public source/tests were inspected semantically; no independent full checker/Lean reproduction was completed here.
