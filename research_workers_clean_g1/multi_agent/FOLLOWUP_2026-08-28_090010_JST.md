### Construct drift is large but mostly hidden in the aggregate

The original v1 prompt asks only for factual correctness. The v2 prompt changes the decision rule to fail if either truth OR responsiveness fails; a response that only asks a counter-question or does not commit to an answer is rejected even if it contains no false factual claim.

On the `assessable` subset (89 items), every one of the six judge families loses judge-human kappa under v2:
- deltas range from `-0.0573` to `-0.5490`
- mean delta `-0.2283`
- mean kappa falls from `0.6052` to `0.3769`
- mean flag rate rises by `+0.2317`

On the `elicitation/no-factual-claim` subset, v2 drives the mean flag rate upward by about `+0.6662`; two judge families reach an all-flagged state where kappa is undefined. Yet if all 147 common items are pooled, the mean kappa delta across six families is only about `-0.0235`, because subset effects cancel. Therefore an aggregate agreement score can conceal a large construct change.

### Cross-family voting is not an independence guarantee

On the common 147-item v1 set, the six-family majority vote has kappa `0.4008`; the best individual judge reaches `0.5342`. Unanimous and any-flag aggregation are lower still (`0.2720` and `0.2776`).

The repository's conditional-independence simulation reports observed mean pairwise judge-judge kappa `0.3523` versus expected `0.1248` under the simulated independence baseline, with the simulated 95% interval `[0.0736, 0.1803]`. The observed excess is `0.2275` and none of 2,000 simulations reaches it (`p_empirical=0` in the deposited table). This is direct evidence, in this corpus, that six different model families share much more error structure than a conditional-independence assumption would predict.

This strengthens the previous LAJ-Gherkin result: model-name diversity and prompt diversity are not themselves residual evidence. The controller must validate that the candidate verifier measures the same construct and has conditional residual value on the current verifier's failure slice.

## Controller refinement: construct identity must precede residual-value calibration

Candidate semantic-correction gate:

```text
1. CONSTRUCT APPLICABILITY
   Is the target construct actually defined on this case?
   If unknown/not-applicable -> ABSTAIN or route to a different construct-specific verifier.

2. CONSTRUCT IDENTITY
   Does candidate verifier B judge the same construct as A/current objective?
   If B adds responsiveness/style/helpfulness or another criterion, do not treat agreement/disagreement as a second factuality vote.

3. CONDITIONAL RESIDUAL VALUE
   Estimate, on calibration slices with minimum support:
     P(B helpful | A wrong, same construct, slice)
     P(B harmful | A correct, same construct, slice)
   Use lower-confidence-bound utility, not model-family count.

4. COST / BLAST RADIUS
   Require stronger lower-bound evidence before destructive promotion when descendant closure, irreversible effects, or replay cost are large.

5. REPAIR ADMISSIBILITY
   Only after semantic correction is sufficiently supported, apply dependency/authority/effect/serving-state rollback checks.
```

## Scope / negative evidence

- The judge-human-agreement corpus is machine-generated STEM tutoring data; it does not establish universal thresholds for other domains.
- The six-family independence result is a corpus-level dependence diagnostic, not a universal correlation constant.
- v2 is not merely a better wording of v1; it deliberately changes the construct by adding responsiveness. Its lower factuality kappa on assessable items must not be interpreted as evidence that rubric prompts are generally harmful.
- The assessable/elicitation partition is defined by the human instrument in this corpus and should not be transplanted mechanically.
- No O, other worker, downstream, legacy/pre-independence state, shared aggregate ledger, or other-role receipt/config was used.
