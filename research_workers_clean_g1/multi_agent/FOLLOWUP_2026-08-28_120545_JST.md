## New mechanism study: repair-risk vector + uncertain symptom anchor
The scalar synthetic blast-radius `H` has been replaced by a componentwise repair-risk vector for a controlled mechanism study. The vector axes are:
- `D`: descendant closure size / amount of downstream work exposed to a wrong intervention.
- `E`: external-effect class (`none`, `reversible`, `irreversible`).
- `A`: authority exposure (`low`, `high`).
- `S`: serving-state confidence (`known`, `unknown`).

Each axis contributes a minimum required probability that the selected intervention-anchor set actually contains the true causal anchor. Hard states (`irreversible` effect or `unknown` attended/serving state in this toy model) cannot be traded off against low descendant count; they force a broad fallback. This is deliberately different from a weighted scalar that lets one risk dimension offset another.

The symptom localizer is modeled as ranking eight possible intervention anchors. Three symptom-quality slices (`good`, `mid`, `poor`) have separately calibrated top-k coverage. Calibration used 1,200 deterministic samples per slice and Jeffreys 95% lower bounds. The repair policy then chooses the smallest top-k anchor set whose lower coverage bound satisfies the componentwise risk requirement; otherwise it falls back to whole redraw.

## Connection to current public MAS repair evidence
Fresh public evidence strengthens the `symptom -> anchor distribution -> repair closure` decomposition:

1. `Repair or Resample? Rethinking Failure Debugging in LLM Multi-Agent Systems` (arXiv:2608.25920, submitted 2026-08-26) introduces SymTrace and the 536-trajectory SymFail dataset with graph-linked failure locations and intervention anchors. Unguided rerun repair was only `6.90%`, while symptom-driven intervention repaired `20.15%`. This supports targeted intervention, but the low absolute repair rate is also strong evidence **against treating a symptom-derived anchor as certain**.
2. `Doctor-RAG: Failure-Aware Repair for Agentic Retrieval-Augmented Generation` (arXiv:2604.00865) explicitly separates earliest-failure localization from tool-conditioned local repair and reuses validated prefixes instead of rerunning the whole trajectory. This is an adjacent Agentic-RAG setting, not direct MAS rollback evidence, but it independently supports the diagnosis-before-repair decomposition.
3. `Candidate supply and answer selection shape the value of LLM judging in multi-agent systems` (arXiv:2608.25937, submitted 2026-08-26) again shows that judge value is conditional on task/generator/candidate rarity rather than a model constant. That remains relevant to the semantic-correction gate upstream of repair scope.

## Controller update
The candidate controller is now:
1. bind the semantic correction to an explicit target/construct and supported slice.
2. estimate residual `p_help/p_harm`; retain `no extra call / provisional / abstain` as competitors when escalation is unsupported.
3. localize the failure symptom, but represent localization as a **ranked anchor set with calibrated top-k coverage**, not a single point anchor.
4. form a repair-risk vector rather than a single blast-radius scalar: descendant closure, effect reversibility, authority exposure, replay cost, and serving-state certainty remain separate proof/impact axes.
5. translate each risk axis into componentwise evidence requirements; hard non-tradeable states cannot be compensated by low values on another axis.
6. choose the smallest union of plausible anchor closures whose **conservative coverage lower bound** satisfies every active risk constraint.
7. if the symptom/localizer slice is unsupported or drifted beyond its robustness contract, enlarge the closure, whole-redraw, or block; do not silently carry calibration across the shift.
8. only then pass the proposed repair through the existing repair-admissibility gate for dependency capture, required results, authority, external effects, and attended serving state.

The new architecture can be summarized as:
`construct-valid correction evidence -> uncertain symptom localization -> risk-vector coverage requirement -> anchor-set/closure selection -> repair admissibility`.
