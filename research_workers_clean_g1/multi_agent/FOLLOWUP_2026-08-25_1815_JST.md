## Frontier action completed: heterogeneity decomposition

### C11 — Model heterogeneity helps only when interaction structure leaves room for complementary priors; prompt-tone diversity is much weaker

Primary source: Nuo Chen et al., *Diversity Collapse in Multi-Agent LLM Systems: Structural Coupling and Collective Failure in Open-Ended Idea Generation*, Findings of ACL 2026. https://aclanthology.org/2026.findings-acl.13/

This source provides unusually direct decomposition evidence.

**Group-size scaling:** Across 20 ICLR topics, increasing group size N=3→7 raises mean Vendi diversity only 3.09→3.32 (+7.4%; paired t=5.46, p<0.0001), while the Diversity Utilization Ratio Vendi/N falls from 1.03 to 0.47. Thus absolute diversity grows, but marginal diversity per agent collapses. Topic complexity does not explain the saturation (r=-0.14, p=0.55).

**Model heterogeneity × interaction structure:** Comparing a single-model DeepSeek-V3 team with a heterogeneous DSV3 + GPT-4o + Claude-Sonnet-4 team, Vendi diversity changes by persona/topology:
- Interdisciplinary / authority-weighted: 2.197±0.343 → 2.943±0.297, +34.0%, p=0.0003, Cohen's d=2.33.
- Leader-Led: 2.285±0.339 → 2.619±0.332, +14.6%, p=0.071, d=0.99.
- Horizontal: 2.755±0.476 → 2.641±0.271, -4.1%, p=0.627, d=-0.29.

This is an important negative result: model heterogeneity is not automatically beneficial. It helps strongly when hierarchical/authority coupling otherwise collapses diversity, but adds no measured benefit in the already-diverse horizontal condition.

**Prompt-level ablation:** Under flat topology, directive vs exploratory prompt tone is statistically indistinguishable for diversity (reported eta-squared 0.023). Senior vs Junior identity has only a small effect and reverses direction under flat topology; identity + tone + interaction explain only 9.2% of total variance in the prompt ablation. This directly weakens the hypothesis that prompt wording alone causes the diversity collapse.

**Topology intervention:** Nominal Group Technique (blind initial writing) maximizes initial diversity, while subgroup topology maintains the strongest late constructive conflict. Dense coordination can therefore contract exploration even when agents are individually capable.

Scope: ideation/research-proposal task family, three-model heterogeneous condition, fixed assignments; not yet a general result for tool-heavy execution agents. The heterogeneous condition is not a full factorial over model/prompt/tool diversity, but it is a stronger causal decomposition than the previously found DEI result.

Mechanism hypothesis: use heterogeneity as a targeted antidote to correlated priors, not as a universal multiplier. Measure baseline independence first; if agents are already sufficiently decorrelated, adding heterogeneous models may have near-zero or negative marginal diversity.

### Supporting negative branch — a single agent can beat role-simulated MAS for pure semantic diversity

Primary source: Cui Encheng et al., *Single-Agent Generation Surpasses Multi-Agent Systems in Semantic Diversity*, Findings ACL 2026. https://aclanthology.org/2026.findings-acl.1894/

Under matched prompt conditioning on divergent-thinking tasks, single-agent setups consistently exceed MAS semantic diversity; a single-agent Multi-Output strategy is reported as the highest-diversity condition without degrading logical validity. This further rejects the assumption that nominally distinct role agents necessarily create independent channels. Detailed table extraction remains open for a later run.

## Updated synthesis

The evidence now separates three knobs more clearly:

1. **Raw N:** low efficiency; N=3→7 yields only +7.4% absolute diversity while per-agent utilization more than halves.
2. **Model heterogeneity:** high value when the existing topology/persona creates correlated consensus (+34% in the strongest authority-weighted condition), but no value in an already-horizontal condition (-4.1%, n.s.).
3. **Prompt tone/persona alone:** relatively small variance contribution in the controlled flat-topology ablation; structural coupling dominates.

This sharpens the resource-allocation hypothesis: first measure correlation/effective-channel deficit; add model heterogeneity only where deficit is high; otherwise prefer independent sampling/multi-output or topology interventions.
