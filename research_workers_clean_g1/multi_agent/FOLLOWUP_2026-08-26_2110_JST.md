## Additional breadth: self-play / self-evolution
A fresh primary-source scan found **SAGE: Multi-Agent Self-Evolution for LLM Reasoning** (arXiv:2603.15255v2, 2026-03-17). SAGE uses four co-evolving roles from a shared backbone: Challenger generates increasingly difficult tasks, Planner structures them, Solver answers, and Critic filters generated tasks/plans; correctness is determined by external verifiers. The abstract reports Qwen-2.5-7B gains of `+8.9%` on LiveCodeBench and `+10.7%` on OlympiadBench across math/code evaluations.

Primary source: https://arxiv.org/abs/2603.15255

### Scope
This supports the possibility that differentiated agent roles plus explicit curriculum generation, planning, filtering, and external verification can drive self-training from a small seed set. It does **not** isolate which role causes the gain, does not establish that four agents is optimal, and is not evidence that self-judging alone is sufficient—the external-verifier component is central to the reported loop. Component-level ablations were not established from the primary page in this invocation, so no component effect size is claimed.
