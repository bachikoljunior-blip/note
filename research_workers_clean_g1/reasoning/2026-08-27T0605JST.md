## C451 — Canonical outcomes and shrinking need to preserve semantic class, not only source syntax

The initial canonical result projection should distinguish at least `DEFINED(canonical_value)`, `UNDEFINED`, `ERROR(canonical_error_class)`, and `UNSUPPORTED(route_support_reason)` outside mismatch scoring. Objects must be key-order canonicalized. Set-like outputs must be canonically sorted or represented as a normalized mathematical set rather than serialized-order bytes. Error text should not be compared verbatim across engines; compare a versioned semantic error class while retaining raw diagnostics for localization.

A mismatch shrinker must preserve the frozen language mode, strict/error projection, numeric model, builtin set, entrypoint type and route-support membership. A syntactically smaller case that falls out of the common support class is not a valid minimized witness for the original mismatch.

This design keeps four evidence classes distinct: executable differential agreement, fixed-corpus conformance, formal-model agreement, and theorem/certificate checking. Agreement across classes strengthens localization but does not become a proof that a production compiler/runtime is universally correct.
