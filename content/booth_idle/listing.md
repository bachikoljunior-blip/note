## 説明文

**設定ファイル1枚を書き換えるだけで、自分の店・商品・チャンネルの放置ゲームになります。**

お客さんに「もう一度サイトを開く理由」を作るための、小さなブラウザゲームです。
キャンペーンページ、店舗サイト、配信者のリンク集、展示会のノベルティ。
置くだけで動きます。

### 何が入っているか

- ゲーム本体一式（HTML / CSS / JavaScript）
- `brand.config.json` … ここだけ書き換えます
- `generator.html` … フォームを埋めると設定ファイルが出てくるページ
- 書き換え例3種（珈琲店・サロン・配信者）
- `validate_config.py` … 設定の誤りを日本語で指摘する検査
- `test_engine.py` … 実ブラウザで20項目を自動検査（開発用）
- README（日本語）／ライセンス

### 変えられるところ

題名・ひとこと説明・アイコン／配色（背景・パネル・文字・強調）／数えるものの名前・単位・絵文字／
タップ対象の絵文字と文言／増やすもの8種の名前・説明・絵文字／強化6種／
到達メッセージ5種／リセット要素の名称／オフライン収入の上限と割合／誘導ボタンの文言とリンク先／
フッター表記

### 技術的なこと

- **ビルド不要。** ファイルを置くだけです。Node も PHP も要りません
- **外部ライブラリなし。通信なし。** あなたが設定したリンク以外へは何も送りません
- **セーブは端末内**（localStorage）。サーバーもデータベースも不要です
- **スマホ縦画面前提。** 片手・タップだけで遊べます
- GitHub Pages / Netlify / Cloudflare Pages / 自社サーバー、どこでも動きます

Chromium で20項目を自動検査しています（起動・タップ加算・購入で自動収入が発生する・
放置で増える・再読込で進行が残る・設定差し替えで題名と配色と通貨名が変わる・
壊れた設定では止まって理由を出す、ほか）。検査スクリプトも同梱しています。

### 注意

- ゲームの**遊びの速さ（値段と毎秒の量）は釣り合いを取った既定値**が入っています。
  変えることもできますが、変えると難易度が変わります
- 効果音・BGM・画像素材は入っていません。表示は絵文字とCSSだけで作っています
- 売上・集客・話題化を保証するものではありません
