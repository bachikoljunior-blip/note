## Newly primary-verified high-value evidence

### 1. HIPIF: hierarchical subgoals + completed-history folding + reflection + local process rewards
Primary: https://arxiv.org/abs/2606.10507
Primary HTML: https://arxiv.org/html/2606.10507v1
Mechanism: organize execution around explicit subgoals. Keep detailed action/observation history only for the current subgoal; when a subgoal completes, fold it into a compact record `[subgoal, terminal observation]`. Train subgoal proposal, completion/transition judgment, and action execution end-to-end with GRPO. Add hierarchical reflection after each step and rule-based local penalties for impossible subgoals, failed terminal observations, repeated action-observation loops, and malformed structure.

Evidence, 3B Qwen2.5 base:
- HIPIF: ALFWorld avg 96.1, VirtualHome 63.3, ScienceWorld 64.8.
- GIGPO: 93.8 / 60.9 / 58.1.
- STEP-HRL: 92.9 / unreported / 61.8.
- HiAgent+GRPO: 85.9 / 48.9 / 46.1.
- On difficult ALFWorld PICK2, HIPIF 95.2 vs GIGPO 85.7.

Ablations, 3B:
- Full HIPIF: 96.1 / 63.3 / 64.8.
- Without hierarchical reflection: 87.8 / 53.9 / 49.2.
- Without subgoal-oriented process rewards: 90.3 / 57.9 / 57.0.
- Without explicit subgoal decomposition + folding: 73.9 / 46.9 / 43.1.
The no-subgoal variant is the largest drop. For 7B, full HIPIF is 99.2 / 68.8 / 71.5 vs no-subgoal 87.5 / 59.9 / 63.5, so the structural benefit persists with a stronger base model.

Efficiency, average steps / input tokens per trajectory:
- ALFWorld: HIPIF 16.5 steps / 16.6K tokens; no-subgoal 38.0 / 37.8K; GIGPO 20.7 / 21.7K.
- VirtualHome: HIPIF 29.5 / 33.5K; no-subgoal 37.1 / 42.8K; GIGPO 30.4 / 35.1K.
- ScienceWorld: HIPIF 15.0 / 22.0K; no-subgoal 19.1 / 28.7K; GIGPO 19.8 / 37.6K.
HIPIF uses no task-specific expert trajectories and no auxiliary model in the reported training pipeline; training used 8×A100 80GB.

Judgment: VERY HIGH relevance to O's recursive Skill-in-Skill / context-folding direction, with stronger causal evidence than the earlier prompt-only folding papers. Three especially important implications:
1. **Subgoal hierarchy + folding is not enough as a prompt trick.** Prompted HiAgent performs poorly; environmental-feedback training changes reliability materially.
2. **Reflection is valuable when attached to stage transition/control, not merely generic self-critique.** The ablation drop is large, especially ScienceWorld 64.8 -> 49.2.
3. **Local process penalties can target unmistakable failure patterns cheaply.** Repeated identical action-observation pairs are penalized without a second judge model, directly addressing no-progress loops.

## Cross-paper synthesis update

HIPIF now forms a stronger triangulation with MiRA, BEACON, Context Folding, MESA, and Skill studies:
- MiRA: explicit active subgoals can improve inference-time success.
- BEACON: milestone segmentation improves credit assignment so late failure does not erase earlier good work.
- HIPIF: explicit subgoals + folding have the largest ablation contribution, and transition reflection/process rewards stabilize them.
- MESA: current context may need several complementary structural views, not only one subgoal branch.
- Skill regressions: procedures can hurt if they become over-prescriptive, so subgoal structure must be evaluated on downstream success/cost rather than assumed helpful.

This suggests an O candidate architecture of **bounded active subgoal + folded completed-state artifacts + selectively reachable raw provenance + explicit transition judgment + cheap environment-grounded no-progress penalties**, with full-context/no-subgoal and deterministic masking controls.

## Candidate matched intervention for O

A factorial test is now more informative than a binary 'recursive routing vs current':
- Factor A: explicit current subgoal vs none.
- Factor B: fold completed subgoal history vs retain full history.
- Factor C: transition reflection/completion judgment vs direct next action.
- Factor D: cheap rule-based no-progress/invalid-transition penalties vs terminal outcome only.
Measure downstream success, task steps, active/input tokens, elapsed time, premature subgoal transitions, repeated-action loops, and stale-context errors. Keep raw provenance externally reachable to avoid irreversible summarization loss.

## Evidence-scope cautions
- HIPIF is trained RL on embodied/text environments; it does not prove prompt-only deployment into O will reproduce the gains.
- The method uses substantial offline training compute (8×A100 80GB); O should first test the structural controls at inference/harness level before considering costly RL.
- Folding stores compact terminal records; for code/research work O may need richer typed completion artifacts and raw provenance pointers because a terminal observation alone may not preserve causal evidence.
- Rule-based loop penalties are attractive where failure is mechanically obvious, but should not penalize legitimate repeated checks unless the environment state is also unchanged.
