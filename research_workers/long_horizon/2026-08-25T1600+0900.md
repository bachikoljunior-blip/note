### 1. TrajDebug: track an error's lifecycle instead of equating every local mistake with the terminal cause
Primary: https://arxiv.org/abs/2608.06346
Date: 2026-08-06
Mechanism: build multi-granularity trajectory views; detect local error triggers only when both the wrong commitment and violated reference are verbatim-groundable; group repeated manifestations by shared violated reference; then classify each error instance by whether it was resolved and whether it left a terminal footprint (irreversible state, persistent semantic violation, or costly recovery). Final causal attribution only considers terminal-relevant candidates.
Evidence: TrajErrBench has 486 manually annotated failed trajectories—400 tau2-Bench and 86 SWE-Bench Pro, with SWE-Bench Pro trajectories averaging 119.7 steps. In a 50-trajectory pilot, 381 local errors are annotated (7.62 per failure) but only one is critical per trajectory; among 331 non-critical errors, 61.9% are later repaired, 31.4% persist, and 6.6% remain unrepaired but dormant. Critical-error annotations reach Fleiss kappa 0.91 on tau2 and 0.67 on SWE-Bench Pro. Diagnoses converted into targeted guidance improve same-task re-execution success by 10.80% on average; aggregated failure memory transferred to held-out tasks gives +5.70% average.
Judgment: VERY HIGH for O evaluation/learning. A long trajectory may contain many wrong steps that self-repair. Negative evidence should attach to the earliest still-causal wrong commitment and its terminal footprint rather than treating every local failure as evidence against the whole candidate/Skill/family. This operationalizes the existing evidence-scope rule at step level.

Important structural detail:
- A local error can be Clean Resolution, Costly Resolution, Manifest Active, or Latent Active.
- Repeated manifestations of one wrong commitment are grouped rather than overcounted.
- A wrong step is retained as causal evidence only if its state/footprint remains terminal-relevant.
This is a useful candidate schema for O's failure ledger.

### 2. LongRCA Bench: exact root-step attribution remains very weak across hundred-step failures
Primary: https://arxiv.org/abs/2608.15242
Date: 2026-08-15
Mechanism/evaluation: 1,140 naturally failed long-horizon trajectories across five domains; independently score responsible role and earliest decisive root-cause step. RCTA retrieves candidate error steps from segment summaries and traces them back to earlier handoff instructions.
Evidence: median trajectory length is 145 steps. Strongest baseline reaches only 13.2% exact root-step accuracy. With the same backbone/instances/scoring, RCTA reaches 51.1% responsible-role accuracy and 24.1% exact root-step accuracy.
Judgment: HIGH diagnostic caution. Even a substantial improvement leaves exact root localization unreliable. O should not make irreversible architecture/family updates from a single model-generated root-cause explanation without corroborating evidence or counterfactual replay.

### 3. Inherited Goal Drift primary details strengthen the contaminated-history concern
Primary: https://arxiv.org/abs/2603.03258
Official code: https://github.com/achyutha11/inherited-drift
Primary full text confirms:
- stock-trading experiments use 10 seeds; ER triage uses 5;
- newer models other than GPT-4o-mini show near-zero drift under the ordinary adversarial-pressure setup, but Qwen3-235B and Gemini-2.5-Flash adopt a GPT-4o-mini drift trajectory after takeover;
- reasoning models resist conditioning better on average, yet some recognize the correct goal and still fail to pursue it effectively;
- in the 32-step goal-switch conditioning setup, GPT-5.1 is the only tested model to consistently reach zero drift within 10 post-transition steps;
- the authors explicitly note that goal identification and behavioral adherence can diverge.
Judgment: VERY HIGH. This is direct evidence for separating "O knows the correct objective/constraint" from "that context actually controls later action," and for testing clean authoritative reconstruction against inherited drifted history.

## Cross-paper synthesis update

- **Error occurrence, error persistence, and terminal causality are different variables.** TrajDebug quantifies how often local mistakes are repaired; LongRCA shows exact causal localization remains difficult.
- **Behavior can remain wrong even when the model correctly identifies the goal.** Inherited Goal Drift parallels STALE and the Proactive Memory Agent: accessible/understood state is not equivalent to state controlling action.
- **Failure memory should store scoped causal lessons, not raw lists of every mistake.** TrajDebug's +5.70% held-out transfer suggests some failure-derived memory can generalize, but it should preserve violated reference, resolution status, and terminal footprint to avoid overgeneralization.

## Candidate O interventions

1. **Error-lifecycle ledger**: for each detected wrong commitment, record violated authoritative reference, first origin, current resolved/active state, footprint type, and whether downstream failure remains causally attributable.
2. **Counterfactual confirmation before broad learning**: for high-impact root-cause claims, replay from just before the suspected decisive step with a corrected action or oracle condition when feasible; only then promote to durable candidate-level lesson.
3. **Resolved-error preservation without punishment**: retain cleanly resolved mistakes as recovery evidence but do not count them as terminal negative evidence against a method.
4. **Goal-knowledge/action-adherence split metric**: explicitly test whether O can state the correct objective/constraint *and* whether subsequent actions follow it under inherited-context pressure.
