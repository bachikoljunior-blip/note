## Newly covered decision-relevant evidence

### 1. TraceRetain: retention-policy gains may be invisible on clean saturated tasks and appear only under memory pollution
Primary: https://arxiv.org/abs/2606.29178
Mechanism: bounded external memory for a frozen action model; score entries by interpretable success, age, access frequency, redundancy, specificity, similarity, and downstream utility, then evict the lowest-scoring entries at capacity.
Evidence: on clean ALFWorld with gpt-5-mini, external memory improves over no-memory across two seeds, but differences among bounded retention policies remain inside Wilson 95% CIs—clean T=100–200 trajectories do not naturally generate enough pollution to discriminate retention strategies. Under a controlled 75% noisy-write stress, unbounded memory Precision@5 falls 20.2% -> 12.4% and FIFO-K50 15.8% -> 3.8%, while TraceRetain-CEM is essentially stable 16.9% -> 16.6% and preserves 97/100 task success. Held-out in-distribution evaluation has memory-augmented policies solving 47–49/50 tasks vs 39/50 no-memory.
Judgment: HIGH evaluation-design value. If O compares retention policies only on clean tasks where memory is not saturated/polluted, a true difference may be structurally unobservable. Precommit controlled stale/noisy/redundant-memory stress alongside natural workloads; a null on easy clean trajectories should not be promoted to a family-level rejection.

### 2. ActionEngine: prevalidated state-machine memory can turn repeated reactive reasoning into one programmatic execution, with localized repair
Primary: https://arxiv.org/abs/2602.20502
Mechanism: a Crawling Agent explores a GUI offline and builds an updatable state-machine memory with validated action templates. An Execution Agent uses that state to synthesize a complete executable Python program for a task. If an evolving interface breaks an action, vision-based re-grounding repairs the local failure and updates memory rather than discarding the whole program/state.
Evidence: on Reddit tasks from WebArena, ActionEngine reports 95% success with on average a single LLM call versus 66% for the strongest vision-only baseline, while reducing cost 11.8× and end-to-end latency 2×.
Judgment: HIGH for repeated O procedure families. This is stronger than plan caching alone: cache *validated transition structure/action templates*, execute deterministically/programmatically where possible, and invoke the expensive reasoning model only for novel state, local repair, or program synthesis. The key assumption is environmental regularity; stale templates need validation/invalidation.

### 3. NetAgentBench: state-centric long-horizon evaluation exposes exploration/coherence meltdowns
Primary: https://arxiv.org/abs/2604.09678
Mechanism/evaluation: finite-state-machine formalization of multi-turn network configuration tasks gives deterministic ground-truth state transitions and bounded execution, making it possible to observe where an agent becomes incoherent rather than judging only final text.
Evidence: four contemporary LLM agents solve basic configuration tasks but exhibit severe exploration meltdowns/coherence collapse on expert-level configurations.
Judgment: MEDIUM-HIGH diagnostic. The benchmark is network-specific, but reinforces measuring O against authoritative external state trajectories instead of only its self-reported plan/progress.

## Cross-paper synthesis update

- **Evaluation must create the failure mode a mechanism is supposed to solve.** TraceRetain joins O's prior contaminated-selector result and scientist-agent evidence-scope rule: a clean benchmark with no memory pressure cannot strongly test retention quality.
- **Experience reuse can move work out of the LLM loop.** ActionEngine suggests that after a state transition/tool sequence is validated, future matched work may be compiled into deterministic programs/templates, with the model reserved for re-grounding and novel branches.
- **State-centric benchmarks make drift visible.** This complements StagedWorkspace's version bindings and canonical-path deviation: authoritative state and expected transition structure can reveal failure earlier than terminal natural-language assessment.

## Candidate matched interventions for O

1. **Memory-pollution stress control**: inject semantically similar failed traces, superseded facts, irrelevant tool observations, and redundant successful traces at controlled rates; compare unbounded, FIFO/recency, deterministic scored retention, and learned future-value retention.

3. **State-transition trace metric**: record authoritative state before/after each meaningful action and detect invalid/no-progress/repeated transitions independently of the model's prose.
