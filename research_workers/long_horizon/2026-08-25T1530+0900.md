## Newly covered high-value evidence

### 1. Goal-Autopilot: mechanically gate terminal success claims on executed falsifiable checks
Primary: https://arxiv.org/abs/2606.11688
Official code: https://github.com/EpistemicaLab/goal-compiled-autopilot
Mechanism: externalize long-running work into a durable finite-state machine advanced in stateless ticks; a hard termination floor forbids `done` unless the relevant falsifiable gate actually executed and passed. Under gate soundness, floor enforcement, and plan coverage, false success is structurally excluded; the failure mode becomes an honest stall.
Evidence: 3,150 paired cells (70 tasks × 3 systems × 3 models × 5 seeds, including 50 SWE-bench Lite tasks over 11 OSS repos). Autopilot false-success rate is 0.95% [95% CI 0.38–1.62], versus Reflexion 8.10% [6.48–9.81] and StateFlow 25.05% [22.48–27.62]. On SWE-bench Lite, StateFlow false success is 33.7% versus Autopilot 0.67%, a paired difference of -33.07 pp [95% CI -36.53,-29.73]. Official public repository exists.
Judgment: VERY HIGH for unattended O termination semantics. The important mechanism is not another evaluator model; it is that completion is a state transition guarded by a concrete executed predicate. This is compatible with long horizons because each tick can rehydrate only durable state. Caveat: it intentionally trades some coverage for honesty, and gate soundness/coverage become the trust points.

### 2. False-success LLM judges are weak; cheap calibrated detectors can be much stronger triage
Primary: https://arxiv.org/abs/2606.09863
Mechanism/evaluation: compare agent completion claims against text-independent environment ground truth in 9,876 tau2-bench trajectories across 8 model families and 1,879 AppWorld trajectories across 4 model families.
Evidence: false success constitutes 45–48% of failures in single-control tau2 domains, 3% in dual-control telecom, and 75.8% among AppWorld self-assessing coding-agent trajectories with explicit status claims. Across 5 LLM judges × 5 prompt strategies, no configuration exceeds AUROC 0.65 on tau2 and judges reach only 0.54 AUROC on AppWorld API traces. Lightweight task-disjoint TF-IDF detectors reach AUROC 0.83 and 0.95, respectively, recovering 4–8x more false successes at the same flag rate with ~3,300x lower latency.
Judgment: VERY HIGH evaluator-design evidence. O should not rely on a generic LLM judge to decide whether it truly finished. Mechanically verifiable state/gates should dominate where possible; lightweight domain-calibrated anomaly detectors can triage suspicious claims more cheaply than a second general model.

### 3. AnalysisBench: stage mixing, poor error localization, and premature termination can dominate model capability
Primary: https://arxiv.org/abs/2604.11270
Mechanism/evaluation: 35 tool-project pairs spanning 7 static/dynamic analysis tools and 10 C/C++/Java projects, with manually built reference setups. Four agent architectures × four LLM backends.
Evidence: custom AnalysisAgent achieves 94% manually verified success (33/35) with Gemini-3-Flash versus 77% for the best baseline ExecutionAgent. The study identifies stage mixing, weak error localization, and premature termination as recurrent architecture failures, and reports that LLM self-validation consistently overstates manually verified success.
Judgment: HIGH. Long-horizon architecture can matter more than merely upgrading the model. O should keep phases/semantic states explicit enough that setup, execution, validation, and completion cannot blur together, while avoiding ritualized process that Skill studies show can itself become harmful.

### 4. DreamFly: explicit termination can be decoupled from action generation in a receding-horizon controller
Primary: https://arxiv.org/abs/2608.12308
Mechanism: causal historical memory + plan-K/execute-one receding-horizon diffusion policy + a separate LiteStop probability derived from initial action logits, rather than leaving stopping implicit inside ordinary action generation.
Evidence: on OpenFly, test-seen/test-unseen success rates are 32.04%/29.46% and SPL 28.22%/23.54%, outperforming compared methods while reducing navigation error.
Judgment: MEDIUM because it is aerial vision-language navigation, but the structural hypothesis is useful: termination can be a separately calibrated head/gate rather than an ordinary natural-language action. This converges with Goal-Autopilot from a very different domain.

## Cross-paper synthesis

- **Termination deserves its own control layer**: false success is common, general LLM judges can be poor at detecting it, and explicit gate/stop mechanisms outperform implicit self-assessment in multiple domains.
- **Completion and capability are different variables**: an agent can solve substantial parts of a task yet terminate incorrectly, or honestly stall despite available capability. Evaluation should score both goal achievement and termination honesty/coverage.
- **Cheap specialized monitoring may beat a second large model**: false-success TF-IDF detectors and COTA's tiny comparator independently support narrow runtime monitors when the target signal is well specified.
- **Finite-state semantics can coexist with model autonomy**: deterministic state transitions/gates need not prescribe the reasoning method; they can constrain only what counts as a valid transition or terminal claim.

## Candidate interventions for O

1. **Terminal hard floor**: no O-level `completed`/goal-achieved state unless named falsifiable completion predicates were actually run against authoritative state and passed.
2. **Separate honesty metric**: track false-success rate and honest-stall rate independently from task success so a stricter gate is not mistaken for capability improvement or regression.
3. **Cheap completion triage**: use domain-specific deterministic/lightweight detectors to flag suspicious completion claims before spending a general evaluator call.
4. **Stage-bound transition checks**: preserve explicit setup/execute/validate/complete states where stage mixing has causal risk, but test each required transition for process-cost regressions.
5. **Independent stop signal experiment**: where O repeatedly terminates early/late, compare natural-language self-stop against a calibrated gate/head using observable progress and authoritative predicates.

## Evidence-scope cautions
- Goal-Autopilot's theorem depends on gate soundness and plan coverage; a missing/mis-specified gate can yield honest stalls or leave uncovered failure modes.
- TF-IDF false-success detectors are domain-calibrated triage signals, not universal correctness judges.
- AnalysisBench has only 35 tool-project pairs, though results are manually verified and architecture effects are large.
- DreamFly is embodied navigation; use only the decoupled termination/receding-horizon hypothesis, not its exact performance as evidence for software/research agents.
