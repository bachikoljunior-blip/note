## Newly covered high-value evidence

### 1. Inherited Goal Drift: a stronger current model can inherit bad trajectory conditioning from a weaker predecessor
Primary: https://arxiv.org/abs/2603.03258
Mechanism/evaluation: compare the same target model from a clean start against runs initialized with a prefabricated trajectory from another agent that already drifted from the original goal. This isolates inherited-context effects from the target model's clean-start capability.
Evidence: modern models are often robust to goal drift from a clean start, but robustness degrades when they inherit drifted predecessor trajectories; susceptibility is model-family dependent. GPT-5.1 is reported as consistently resilient among tested models. Hierarchy-following scores are poor predictors of inherited drift, and preliminary emergency-triage transfer suggests the effect is not confined to one benchmark style.
Judgment: VERY HIGH for O. This directly supports testing whether long-lived accumulated O context can propagate a predecessor's mistaken framing even when the current base model is capable of better behavior from a clean authoritative state. A stronger model should not be assumed to automatically cleanse contaminated inherited history.

Candidate matched O test:
- same target model/harness/task and authoritative external state;
- condition A: clean reconstruction from minimal authoritative kernel + current facts;
- condition B: full inherited trajectory containing an earlier drift/failure pattern;
- condition C: inherited trajectory folded to verified completion artifacts + raw provenance pointers, excluding failed speculative reasoning;
- compare goal adherence, constraint following, completion quality, elapsed cost, and whether earlier mistaken premises still control later actions.
This is especially relevant to checkpoint/rewind: a context reset may have value even when no model or environment capability changes.

### 2. Counterfactual Trace Auditing (CTA): aggregate task success can hide large Skill-induced behavioral changes
Primary: https://arxiv.org/abs/2605.11946
Mechanism: pair with-Skill and without-Skill trajectories for the same task, align them by goal phases, then identify Skill Influence Patterns such as literal copying, off-task artifact creation, excess planning, or altered recovery behavior.
Evidence: on 49 SWE-Skills-Bench tasks with Claude, aggregate pass-rate change from Skills is only about +0.3 percentage points, yet CTA identifies 522 concrete skill-influence instances. Effects are often hidden on high-baseline tasks due to outcome saturation; moderate-baseline tasks show more recoverable behavior differences, sometimes at increased token cost.
Judgment: HIGH for O's recursive Skill-in-Skill evaluation. A Skill can materially alter trajectory structure/cost even when pass/fail barely changes. Therefore Skill evaluation should retain matched no-Skill/alternative-Skill traces and measure procedure burden, recovery behavior, context use, and downstream outcome. This complements prior evidence that apparently relevant Skills can cause functional and efficiency regressions.

### 3. CoRe / imagined recovery: recover to the nearest viable continuation rather than always restarting from the beginning
Primary: https://arxiv.org/abs/2608.14822
Domain: robotics / vision-language-action, so transfer is speculative.
Mechanism: detect deviation, imagine a viable continuation from a recent good state toward the original goal, minimally realign the physical system to rejoin that continuation, and preserve already completed progress instead of resetting the whole task.
Evidence: primary abstract reports success improvements up to +85.0 percentage points near nominal conditions and a 42.2% reduction in physical restoration actions across simulators/backbones/real-world settings.
Judgment: MEDIUM as a cross-domain recovery hypothesis. It aligns with AgentRewind but emphasizes the *nearest viable continuation* and preserving completed progress. For O, recovery candidate should prefer restoring the latest trustworthy checkpoint that still preserves verified-good completed work, rather than defaulting to full restart.

## Cross-paper synthesis update

- **Inherited context is itself an intervention variable.** Long-horizon evaluation should compare full inherited history against clean authoritative reconstruction, not assume the former is always more informative.
- **Skill effects require trajectory-level causal auditing.** Outcome-only metrics can miss both harmful procedure inflation and beneficial behavioral stabilization when success is saturated.
- **Recovery target selection matters.** AgentRewind + canonical-path drift + CoRe suggest recovery is not binary continue/restart: choose the latest viable checkpoint that removes contaminated future context while preserving verified-good progress and monotonic external-effect state.

## Candidate O interventions

1. **Inherited-context A/B/C test**: clean kernel vs full failed/drifted history vs folded verified artifacts with raw provenance. This directly tests the user's prior concern that long-lived context can suppress better hypotheses/behavior.
2. **Skill counterfactual audit**: for high-impact Skills, archive matched no-Skill traces and score action differences, excess verification/planning, recovery behavior, token/tool cost, and final task result.
3. **Nearest-viable recovery selector**: among available checkpoints, choose the latest checkpoint satisfying authoritative-state alignment, no known contaminated premise, and preserved completed-good milestones; compare against full restart and uninterrupted continuation.

## Evidence-scope cautions
- Inherited Goal Drift results are model/task conditional; use the matched experimental design, not any claim that all long context is harmful.
- CTA's 49-task Claude study is small for precise aggregate success estimates; its strength is mechanistic paired attribution, not the +0.3 pp headline.
- CoRe is robotics-specific; do not promote its exact gains as software/research-agent evidence without transfer tests.
