## First comment

I built this because OpenAI's Assistants API is scheduled to shut down on August 26, 2026.

The free checker scans pasted code for legacy Assistants, Threads, Messages, Runs, and Run Steps usage. It also inspects Responses tool-loop JSON for six common state-risk patterns. Everything runs in the browser; pasted content is not uploaded or stored.

The free checker works without signup. An optional paid migration kit adds a scanner, conservative codemod, and checklist for teams that want a repeatable local workflow. It does not include consulting, custom implementation, or ongoing support.

I would especially value feedback on false positives, missed migration traps, and tool-loop states that deserve an additional check.
